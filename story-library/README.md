# 独立故事文献库

版本：0.1（结构入口）  
更新时间：2026-10-12。当前仅建立职责与目录入口；新故事候选尚未选定，历史研究交付内容未迁入或批准为正史。

本库是下一版故事研究和创作的唯一正文归属，独立于玩法计划、工程实现和运行时内容。可脱离游戏源码阅读；后续相对链接须留在本库内部。

## 资料职责

建议按需要逐步形成以下资料，不为目录完整而预建空文档：

| 资料类别       | 收录内容                                                     |
| -------------- | ------------------------------------------------------------ |
| 来源与阅读记录 | 来源、实际阅读范围、可信边界、引用位置和采用理由             |
| 世界与人物     | 世界事实、组织、人物目标、关系变化及其版本状态               |
| 知识与技术背景 | 文献支持的知识、角色认知、争议解释和认知前置；不定义游戏数值 |
| 故事与因果     | 主线、短任务、事件、证据和人物行动之间的因果关系             |
| 命名与决策     | 名称候选、检索范围、选定理由、被否决项及变更记录             |

每份候选资料须区分来源事实、作者设定、角色相信和玩家已观察，并标记候选/已批准/历史。稳定编辑 ID 仅用于资料交叉引用；它们不自动成为机械 ID、存档字段或玩家可见事实。

## 与工程资料的边界

- 本库不维护技能、配方、资源数量、XP、周期、工具效果、存档字段、工程路径或实施进度。
- 工程侧的技能、物料、解锁与采用理由在本库之外维护；实际游戏行为只由经过工程审核并实现的规则定义决定。
- 准备入游戏的故事/知识条目，由工程在内容资料库维护包外映射：故事编辑 ID 和版本 → 机械/文案 ID、获得条件、可见范围、批准依据。文献依赖不自动成为科技树前置。
- 0.8 故事记录与治理继续归属原工程资料；新版故事正文不在旧版文档目录复制维护。

## 初始状态与接收规则

已交付的候选包仍是独立研究输入，原始 ZIP 按交接规则留存。入库前由本次任务的审阅者核对来源、命名检索边界、故事因果完整性和 Melvor 式技能核心适配，再由用户选定题材及正史版本。未通过的材料保留在独立工作副本，不覆盖已批准正文。

每次故事库修订写明输入版本、可写文件、变更摘要和未解决问题。玩法可用通用功能词先行推进；故事研究不能直接改 `PLAN.md`、工程候选参数或代码。
