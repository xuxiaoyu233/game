## 本地晋升与 Lv20

- 可晋升：`WheatFarm`、`LoggingCamp`、`StoneQuarry`、`LumberMill`、`Warehouse`。
- 条件（`campPromoteBlock`/`campPromotionRequirementsMet`）：工坊时代、对应许可、1 星且**已完成 Lv10**、无施工/升级订单、设施未暂停；费用另计。任一失败返回具体原因且不扣费（重复晋升返回“已是2星”）。
