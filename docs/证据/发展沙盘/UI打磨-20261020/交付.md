# UI 打磨交付：技能页主体化、资源芯片与数值反馈

日期：2026-10-20。执行方：CodeBuddy。范围：在 PLAN 第 2 步“放置主循环样板”的既有规则与存档上，只改**展示层与交互组织**——技能页从“四卡平铺”改为“技能轨 + 单技能主面板”，资源条改为芯片，补一层数值反馈，地图地点胶囊加类型点。不改规则、数值、命令、schema5/`d1-c-1`，不新增第二库存或自动选择。

## 1. 产品判断

用户反馈“UI 还需要很大的进步”。现状不是配色问题，而是三点：信息层级平铺（技能卡里 8 类元素同权）、缺少成长主体（没有一个“我在做什么、赚多少”的大展示）、几乎无反馈（产物入账时数字静默跳变）。本轮按“一次一个技能、一个对象一个主操作、数值变化必须被看见”重排。

参考与取舍：
- **Melvor Idle**（用户点名）：左侧每技能一按钮、正在训练的技能高亮，中央只放一个技能窗口（顶部经验条、动作格、Start）。取“单技能展开 + 动作作为行”；不取左侧竖排（本项目顶部已有导航，竖排会挤压世界）。
- **RuneScape 技能面板**：等级是徽章而非一行小字。取“圆形等级徽章 + 经验条”。
- 放置游戏反馈层通用做法（上升数字、进度条、升级提示）：取“产物飘字 + 数字缓动 + 周期闪烁 + 升级徽章脉冲”，全部为纯展示。

## 3. 交互规格（本轮冻结）

- **进入技能页**：默认聚焦“正在训练的作业所属技能”，否则第一个可开始作业所属技能，否则伐木。切技能**不停止训练**（顶部 strip 与技能轨绿点仍指向真实训练）。
- **开始/停止**：只有一处入口——当前动作卡或动作行的主按钮。空闲时推荐卡给唯一“开始”；训练中给唯一“停止”。
- **动作行状态**：`需 Lv3` / `需农田` / `需研究`（锁定）、`进行中`、`推荐`、`开始`。锁定行无按钮。
- **缺口**：`下一项：择木采伐 · Lv3 解锁`；需要外部条件时才给一个跳转按钮（研究与设施）。
- **弃进度提醒**：训练进度 > 0 时在当前卡显示“切换或停止会放弃当前 N/M 秒进度”。
- **反馈**：产物入账 → 资源芯片 `+N` + 数字缓动；周期完成 → 当前卡轻闪；升级 → 徽章脉冲 0.9s + 右上角“升至 LvN · 解锁××”1.4s。
- **可达性**：技能轨 `role=tablist/tab/tabpanel` + `aria-selected`；主操作 ≥44px（技能轨 53px、地点胶囊 44px、相机钮 44px）；数字统一 `tabular-nums`。

## 5. 自查发现并修掉的缺陷（本轮）

1. **选中技能在悬停时不可读**：共享样式 `.sandbox-game button:hover:not(:disabled)` 的优先级高于选中态规则，悬停把深绿底改回纸色，白字落在纸上。改为 `body.camp-v1 .camp-skills .camp-skill-tab[aria-selected="true"]` 并让 hover 只作用于未选中项。
2. **同一动作出现两个开始/停止按钮**（推荐卡 + 列表行），以及**等级缺口生成指向本页的死按钮**。改为列表用 chip、缺口在等级类时只给文案。
3. **图标变形**：把 padding 加在 mask 元素上，背景色铺满 padding 而 mask 被拉伸成色块。改为独立图标槽（外层底 + 内层 15–17px 图标）。
4. 经验条原本拉满整行（1000px），改为限宽 460 并与 XP 文案同行。

## 6. 已知限制与下一步

- 技能轨用 `role=tab` 但暂不支持左右方向键切换；点击、Tab 焦点环与 Enter/空格可用。
- 技能图标仍是资源图标（木材/石材/谷物/板材），没有独立技能徽记；若要更像 RuneScape/Melvor 需新增一套技能图标（新增 public 素材，超出本轮可写范围）。
- 地图页只做了胶囊类型点与 44px，没有做图标化胶囊、选中标签重绘（Pixi 文本），也未改背景分层阴影。
- 数值速率仍只表示“自动收支”，训练产出显示在动作卡与 strip；未在芯片上合并训练收益（会与现有口径说明冲突）。
- 未做真人试玩与动效节奏调参（飘字 0.9s、缓动 420ms、脉冲 0.9s 为初值）。
- 存档与规则未变，旧档直接生效，无迁移。
