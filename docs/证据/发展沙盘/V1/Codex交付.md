# V1 Codex续修：固定场景与舒适经营原型

2026-10-20。本批直接实现于 `next/civ-idle/`，本地可玩并完成定向验证，待审美与真实节奏试玩。历史 `交付.md`、`复核-20261019/`不覆盖为本批结论。活动状态只见根PLAN。

## 产品与实现

用户最终选择：同一处固定场景，购置/升级/升星逐步完善设施；舒适经营为主，生存风险为后期自愿挑战。普通生产自动入账、现4h离线继续，不增加必须领取的仓库、连点体力、死亡或重大事件暂停。原expand仍保留同一费用/四位开放，玩家改称“整修院落”，场景边界不扩大。

- 空森林环境＋真实设施层；14个透明手绘微缩sprite与宽背景进入原图集，覆盖八建筑及五基础建筑1→2星。建设完工才出现建筑、晋升才换结构。原夜间工坊完整图仍是氛围参考，没有当成未建背景。
- 唯一catalog管理资源/视图/固定锚点/命中轮廓，逻辑Grid与tile ID不变。原图、哈希、制作/处理边界见 `next/civ-idle/assets-source/town/SOURCES.md`。当前66登记项＝50图集帧＋16 public文件，其中新town项15个；旧35帧没有假称为新素材。
- 桌面默认主场景＋短摘要，详情按需展开侧栏；手机摘要/详情与底部五Tab；短横屏由body实际滚动。六资源总览保留，标签与读数分行；空地优先展示一个建议设施，其余按需打开，不改变建设资格。
- 经验、名义收益和机制明细按需查看；建筑费用/前后效果、合法缺料排单、研究缺项导航/返回及保存风险保留。补明确的升级前置说明，未解锁时不能只写“已达Lv1上限”。
- 真实协助成功后短浮显实际资源/截断后XP，满级不显示虚假XP；10秒冷却不改。选择不发奖，拖动不当点击；自动产出不逐tick弹提示。

实际走查发现并修复：功能Tab被摘要高度裁切；fit目标被覆盖；资源挤压；Pixi事件误用页面坐标导致点击错位；取消触控残留指针；短横屏Tab无法滚入视口。相机输入统一为画布坐标，轮廓拾取最终仍返回原逻辑tile。
