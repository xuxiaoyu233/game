- 手机 `420×600`：世界可视高度仅 **150px**（顶栏 150 + 面板 140，footer 被面板覆盖）。
- 首次相机按固定 `570/620` 缩放，手机只剩窄条；各面板用相互覆盖的固定像素偏移定位。

## 实际改动（按任务）

### 任务一：布局、资源摘要、原相机适配

- 新增 `src/css/camp-shell.css` 作为**页面几何唯一来源**（body grid + Flex 区域），替换 `sandbox-tokens.css` 中相互覆盖的固定 `top/bottom` 偏移；`main.tsx` 引入该表并为 body 加 `camp-v1` 类；`index.html` viewport 去掉 `user-scalable=no`（页面/双指缩放不被全局禁用，符合任务要求）。
- `sandbox-tokens.css` 仅删除与 shell 冲突的定位规则，组件外观样式保留。
- 桌面 `≥900w & ≥500h`：世界 + `300–340px` 对象面板双列，面板独立滚动；其余页面（技能/研究/民生/设置）独占主区正常阅读。
- 手机：顶栏（时代 + 3 个关键资源 + 仓容）＋目标条＋世界＋选中对象短摘要（≤86px）＋动作行＋底部五 Tab；“全部资源”展开六资源总览；选中对象“详情/返回营地”切换展开详情占主区。
- `高<500` 短屏（如 `844×390`）：`height:auto` 任务视图，页面滚动、世界保留带状可视区。
- 相机：`WorldScene.fitCamp()` 用 `Camera` 原变换计算当前开放营地＋边缘的可视包围盒（含 sprite 半径/边距），首次进入与“适应营地”按钮共用；“放大/缩小”按钮走 `zoomStep()` 原镜头换算；`onResize` 缩放范围改为 `Math.min`（保证 fit 后范围仍可达）；手动 pan/zoom 不被每次渲染重置（`viewportCenter/Zoom` 模块态保留）。
- `CampHud.tsx` 重排为：顶栏（时代/仓容/资源行/总览切换）、资源总览浮层、面板（`#game-ui`）、导航、世界浮层相机组、目标条、动作行；`#game-canvas` 与 `#ui-root` 同为 body grid 子项（`#ui-root` 用 `display:contents`）。

### 任务二：五 Tab、文案、状态与动作（语言合同）

- 删页头介绍段：研究页、设置页、技能页的“把生产成果投入…”“自动运行…会等待…”“缺料/仓满会等待…”等机制长解释；正常状态不再给长教学（民生正常态原长段删除，仅短缺时给原因＋满足率）。
- 内部编号退出：`CampTilePage` 删 `slot.id · 营地设施`；面板头改为状态 chip（生产中/施工中/已暂停/未开拓/可建设）＋建筑名＋等级/星级；桌面“展开/收起”与手机“详情/返回营地”双按钮按断点切换（绝不并存）。
- `data-panel`（none/collapsed/expanded）同步到 `body`，驱动 shell 的短摘要/展开/隐藏。
- 资源顶栏为“自动收支”短标签（带 `/秒`），详情用分项＋“不含训练、建造”短说明；数值口径为原 IO 减人口需求，与共享投影一致，不伪造历史净变化。
- 保存：状态行完整可见、不截断；失败文案为必要后果（如保存失败可重试），不只有“失败”两字；保存/导出入口保留在设置。
- 字号基于真实 CSS 像素（正文 14–16、按钮 ≥14、辅助 12–13、主库存 16–20）；触控主要目标 44×44（手机资源/相机/目标条/快捷），桌面主动作 ≥36；长中文换行、说明不只靠 hover；关闭详情后焦点回触发按钮。

### 任务三：同场景美化与成长反馈

- `camp-tile-art.ts` 的 `addRankStructure(type,…)` 按建筑类型绘制 **2 星主结构**：农田田垄/作物、伐木棚架与作业棚、采石 timber scaffold、木工坊带锯台的全顶棚、仓库高顶与货架行；`addPlankYard` 为木材加工研究附件（侧边料棚），使该 `visualKey` 差异可见；`addEraMood` 为工坊时代 HQ 旗标＋空地工坊标记。
- 标签改用玩家名（营地中心/林地/石堆/各建筑正式名）＋等级/星级，远景（缩放 <0.55 且无选中）隐藏非选中标签，选中地块始终显示名称。
- **未新增 PNG**：沿用 `sandbox-art-catalog.json` 现有 51 项/35 世界 PNG 与已有图集（`textures_sandbox` 91KB）；2 星结构为代码原型绘制，未伪报正式美术。地块命中/footprint 不随图变化，装饰不截邻格。
