## 首版风格与现成来源

当前V1采用固定森林院落的手绘微缩方向，UI用深绿/暖金，保留清楚轮廓，不全项目转像素画。[最新调研](../规划/网页画质与点击体验调研-20261019.md)查到原包SVG，矢量拆分留作已调查的替代路线；用户新方向后采用手绘微缩样板；清楚边缘不代表细节已完善，也不先替换整套。同一场景逐步增加和完善设施，共用画法、比例和视角；星级用屋顶/基座/固定设备改变主结构，等级用堆料/田垄等少量部件增长，时代改变公共风貌。不要求逐建筑复现概念图细节。原全景留概览/风格参考，不作为动态建设地板。

## 从素材原型到经营场景的美学目标

现有35张素材能指导接线，但通用棚屋和高饱和绿地仍是原型，与夜间工坊概念图有差距。先把同一真实沙盘的比例、层次和功能辨识做好，再追加数量；不因已经有25组组合就宣布美术定稿。

- 世界沿统一微缩2D画法：地形降低饱和度/对比，建筑保留清楚轮廓，少量暖金灯光指示活动；使用terrain独立tint/叠加，不整体压暗到资源和设施不可辨认，不为调色更改源文件。
- 农田先补田垄/作物、灌溉渠与棚架；木工坊补可辨认加工部件。升级增加结构与工作范围，时代改变材质/设备；土地位置与建筑身份持续保留。机械设备、烟气必须匹配已上线状态。
- 场景保持主体：960×720以世界＋当前对象侧面板为主；手机采用看营地/看详情切换，默认短摘要，完整六资源总览一次可达。正常420×600营地视图无遮挡世界高至少270px，短屏/放大字体走任务视图。详细口径见适配规格，不再沿“四资源2×2”和固定top/bottom挤地图。
- 顶栏按“库存/净速率/容量”分层，文字以14–16px为基础；主要操作有明确标签，状态用图形/文字共同表达。缺料、缺人、仓满分别指向可采取的动作，不展示原始school/science字形名。
- 文字按唯一[语言合同](../内容资料库/界面语言与信息层级.md)先审必要性：常态无介绍段/重复机制说明；内部标记退出玩家界面，必要名称/数值/状态/动作清楚呈现。
- 科技页六张卡片按农业/生产/仓储与两时代收拢，清楚解释收益/前置；晋升许可标明“可为建筑升星”，不冒称研究即已改造全营地。远期内容不铺满主界面。环境上线后只增加一条预警带和可选覆盖层，未实现时不放假温度/污染值。
- 微动效只表现真实协助成功、开工、等待恢复、完成和已上线环境变化；减少动效选项保留，飘字合并，不靠闪烁/红点制造操作负担。暂停只作旧档恢复状态，不恢复日常生产暂停按钮。

点击采集沿同一地块上下文面板，显示资源图标/单次收益/真实剩余节奏，成功才轻反馈；选中或拖镜头不授予，动画不发钱。复用现有木/石/粮图标，不另做巨大收获按钮、每资源一套进度面板或烘焙倒计时PNG。自动产出和离线结果仍无需领取；D1-A只露已可操作功能。

完整科技图按[产品目录](../规划/产品功能与科技目录.md)的六分支/时代过滤，默认聚焦当前可研究和下一目标的前置；36节点是长期目录，不要求首屏展示36个灰色锁。节点ID/依赖是规则数据，排版/连线为投影；未来电气/生态保持同画法，不切六套美术风格。

### 等级、星级、科技与时代各画什么

| 状态维度  | 视觉责任                                                     | 控制工作量与防止失真                                                  |
| --------- | ------------------------------------------------------------ | --------------------------------------------------------------------- |
| 星级/阶级 | 改变建筑主轮廓、屋顶、基座、固定设备；1→2星肉眼能分辨        | 首版五建筑×两星级共10种主结构；星级就是阶级，不再制作第二套阶级资产。 |
| 连续等级  | 每星级2–3个细节段增加田垄/堆料/器具，面板始终显示真实等级    | 不为Lv1–20逐级画整屋；同等级段允许共用部件。                          |
| 科技      | 灌溉等实际生效的研究叠水渠附件；升星许可本身只更新可操作状态 | 不能研究轮作后立即把所有农田画成2星；当地晋升才换主结构。             |
| 时代      | HQ/道路/公共装饰与氛围，决定可获得的材料风貌                 | 不自动替换所有旧建筑，不把1星农田画成已机械化。                       |
| 扩地      | 推开相邻边界、显露资源点/通用空地，场景密度和轮廓增长        | 旧HQ/水岸等地标保留；功能片区由玩家布局形成，不是切地图标签。         |

建议展示选择输入为 `buildingId / sandboxRank / levelBand / researchAttachments / eraStyle`，映射至唯一catalog中的主结构和部件；这是展示派生键，不能整串写进玩法存档。逻辑占地不因大星级图片扩张，超出格子的装饰要处理排序/遮挡/点击，不能盖住邻格操作。

农田从开放田垄（1星）变为规整围栏/固定棚架（2星），后续工具设施（3星候选）、机械温室（4星候选）；伐木场从原木堆变有顶作业场，采石场增加永久支架/轨车，木工坊从开放锯台变有顶加工坊，仓库从露天堆场变屋顶货架。每类同时保证剪影辨识，避免五座通用棚屋只换图标。

已有**25组组合是此前三级/时代合同的原型联系表**，保留文件/证据。D1更新catalog时明确主结构/部件复用与2星缺项，D2完善10种主结构；不做建筑×等级×星级×时代全排列。后续四星约20种、六星约30种旧五建筑主结构仅为分批预算，新增建筑另计；不是先把全部未来素材画完的任务，也不声明未来变体已备。

## 原图、图集、UI与引用合同（已有接线，V1完善）

沿已有Vite spritesmith与Pixi Assets，不从零写资源管理器：

```text
next/civ-idle/
  assets-source/                    # 可选编辑母版、来源/许可，不作为运行URL
  public/art/                       # 保留A0的概览图、纹理
  public/icons/                     # 挑选的小SVG，源图本身可直接使用
  src/textures/sandbox/              # 新首版世界PNG单图，既有插件打包输入
  src/images/textures_sandbox.*      # 生成PNG/JSON，不手工编辑
  src/scripts/art/art-manifest.ts    # 保留A0辅助清单
  src/scripts/art/sandbox-art-catalog.json # 当前51项、状态视图绑定、数字锚点、来源
  src/scripts/art/camp-assets.ts     # 已有：唯一catalog的公共URL/key解析
  src/scripts/art/camp-tile-art.ts   # 已有：真实状态派生的世界视图/部件
  src/scripts/ui/sandbox/            # 最小复用组件
  src/css/sandbox-tokens.css         # 颜色、字号、间距、边框
```

目录是新文件的推荐落点，不搬动全部上游源码。原包ZIP留忽略缓存，只保留采用的输入和许可；不为“原图/运行图”机械重复每张未处理PNG。需要编辑母版时才放assets-source，不把整包未用素材塞进public。

**实际生成顺序**：A已补`scripts/prepare-atlases.mjs`，沿既有插件依赖等待PNG/JSON落盘；dev/compile先执行它，随后tsc/Vite。图集位于src/images，`.gitignore`仅精确忽略textures_*.png/json与对应指纹，不忽略整个输入目录。源hash未变化可跳过；干净环境从输入重建，不要求提交生成图或购买另一套打包工具。

统一通过资源key引用：

- public单图沿已有`publicArtUrl('resource.grain')`等key与BASE_URL；不写本机路径、`/public/...`或跨工程相对读取。
- 世界贴图由Pixi Assets/Spritesheet装载，key映射到atlas/frame；React与Pixi共用同一清单，不每帧创建Texture。
- 记录至少包含kind（文件/图集帧）、URL或atlas/frame、源尺寸、数字anchor、逻辑格显示宽度、命中策略、采样方式、sourceId与用途。建筑通常底部锚点`{x:0.5,y:1}`，不解析当前中文anchor说明来计算位置。
- 可用事实与审美阶段分开：present/missing之外，标reference/prototype/approved。A0的ready不自动代表正式建筑素材批准。像素素材按实际需要nearest，其他素材linear，不将所有文字强制像素化。

## 可复用的补图提示词（可选手绘路线）

以下保留早期概念图手绘路线，供后续确实选用该路线时生成/编辑；不是本轮简化六角首版的必做项。D1 优先挑选/组合现成系列，缺项补图应引用当时实际采用的小样，不能拿这些手绘提示词混入另一套风格。本轮没有调用生图工具。

**农田小样**：

> 以附图夜间矿场与木工坊为唯一美术风格参考，制作可用于同一放置沙盘的独立农田素材。固定斜俯视相机和光向，深蓝夜色、自然石木材质、少量暖色灯火；画面只包含一块整洁田地、少量作物和低矮围栏，不含人物、文字、UI、山体或完整景观。透明背景 PNG，底部接地点清楚，整件物体不裁切，四周留少量安全边距。请交单件农田，避免把多个变体连在同一张图里。

**农田升级部件**：

> 以已确认的农田图为基准，保持相机、比例、光向和地面接点一致，制作独立灌溉升级部件：低矮水渠、小储水桶和整齐增加的田垄。透明背景，适合叠在原农田周围；不要重画整个场景，不加人物、文字和 UI。若无法只输出部件，另交一张布局完全对齐的升级后农田图。

**木工坊小样**：

> 以附图为风格参考，制作同一世界中的独立木工坊建筑，使用相同斜俯视角、尺度和光向，深色木梁、石基座、锯台、少量整齐木板和暖色窗光。透明背景，清楚的底部接地点，无完整地形、人物、文字、UI，完整轮廓不裁切。保持木工坊身份，不把原图的冶炼炉直接冒充木材加工设施。

生成结果还需检查真实 alpha、边缘杂色、缩小后的轮廓、同场景透视和落地感。PNG 扩展名本身不证明透明；现有全景和角饰均是 RGB。
