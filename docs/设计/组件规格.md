# 组件规格（Stage 1：SkillRow / IconSlot / StatusBar / TabPlate）

更新日期：2026-10-17。本页给四个基础组件的 anatomy、状态、尺寸与令牌引用；令牌值见 `tokens.json`，颜色只引用语义角色，不写死 OKLCH。四组件均不引入外部库，仅用现有令牌 + 内联 SVG。

## 0. 图标 SVG 规格（全局，先行约定）

与 `src/app/skill-prototype/Icon.tsx` 现有 GLYPHS 契约一致，新字形必须满足：

| 项       | 规格                                                                                   |
| -------- | -------------------------------------------------------------------------------------- |
| 网格     | 24×24 viewBox                                                                          |
| 描边     | 1.75，圆角端点（round linecap）、圆角拐角（round linejoin）                            |
| 结构     | 双层 path：主形层 + 细节层（细节层可用 `opacity 0.6`），禁止填充色块                   |
| 颜色     | 仅 `currentColor`；色相由外层 tone 容器（--tone-gather/-craft/-support）或语义角色赋予 |
| 显示尺寸 | 行内主显示 1.4rem；与文本同行的活动/关系/搜索图标 1.2rem；迷你窗角标 20×20             |
| 回退     | 未登记 ID 回退中性菱形，禁止空洞占位与位图图标                                         |

动作族 15 个图标意象见 `动作族映射.md` §2「视觉表达」列。

## 1. SkillRow（技能行）

技能列表/技能网格的单行载体，双列档左栏与 compact 档 SkillGrid 共用。

### anatomy

```
┌─────────────────────────────────────────────┐
│ [IconSlot 40×40]  技能名（heading）    Lv n │  ← 主行 16
│                ▓▓▓░░ 经验条（5px）   下一级 │  ← 次行 caption
└─────────────────────────────────────────────┘
高 56 = padding sm(6.4)×2 + 主行 16 + gap 4.16 + 次行 11.2 + 经验条 5 + 余量
```

| 部位     | 令牌                                                       |
| -------- | ---------------------------------------------------------- |
| 容器     | 高 56、radius-md、padding `sm md`、surface 底、border 描边 |
| IconSlot | 40×40，tone 容器色相按技能语义组（gather/craft/support）   |
| 技能名   | font-heading，text                                         |
| 等级     | font-body，muted；满级时 accent                            |
| 经验条   | progress-height-sm 5px，track/fill 语义色                  |
| 次行     | font-caption，muted                                        |

### 状态

| 状态     | 表达                                                                                          |
| -------- | --------------------------------------------------------------------------------------------- |
| 默认     | 如上                                                                                          |
| 训练中   | **整圈 1px accent 描边 + 外发光**（accent-soft 光环 + era-glow）；不使用侧边条纹（违反禁令①） |
| hover    | surfaceRaised 底，--motion-fast                                                               |
| 选中     | accentSoft 底 + accent 描边                                                                   |
| 键盘聚焦 | accent 2px 外描边（focus-visible）                                                            |

## 2. IconSlot（图标槽）

所有图标的统一容器；位图插画不许进 IconSlot。

### anatomy

容器 = 圆角方形底（tone 色 12% 透明度 + tone 色 30% 描边）+ 居中 SVG 字形（currentColor = tone 色）。

| 档位 | 容器  | 字形           | 用途               |
| ---- | ----- | -------------- | ------------------ |
| sm   | 20×20 | 12             | 迷你窗动作族角标   |
| md   | 28×28 | 16             | 暂停键、工具行图标 |
| lg   | 40×40 | 22.4（1.4rem） | 技能/物品主行      |

### 状态

跟随宿主组件状态变色（tone → accent 在选中/训练中态）；无独立交互态。disabled 时容器 opacity 0.45。

## 3. StatusBar（常驻状态栏）

三态共用；active/tree 为玻璃条，idle 态被迷你窗取代（迷你窗是其裁切变体，不是新组件）。

### anatomy

```
┌────────────────────────────────────────────────┐
│ ● 活动名 — 产物 ×n/周期        速率  x.xx/分钟 │
│ ▓▓▓▓▓▓░░░░ 进度条（6px）                       │
└────────────────────────────────────────────────┘
高 ≈52：padding 2.4+4.16 + 状态行 16 + gap 4.16 + 进度 6 + meta 行 16
```

| 部位   | 令牌                                                                   |
| ------ | ---------------------------------------------------------------------- |
| 容器   | glass（fill/highlight/border/blur 6px）+ shadow-panel + radius-md      |
| 状态点 | 8×8 圆点，进行中 tone 色呼吸（≤--motion-slow 循环），暂停时 muted 静止 |
| 活动名 | font-body，text                                                        |
| 速率   | font-caption，muted                                                    |
| 进度条 | progress-height-md，fill=accent，仅 scaleX 动画                        |

### 状态

| 状态   | 表达                                                           |
| ------ | -------------------------------------------------------------- |
| 进行中 | 状态点呼吸 + 进度循环 + 速率实时                               |
| 已暂停 | 状态点静止 muted + 进度冻结 + 文案「已暂停」                   |
| 空闲   | 单行「未在训练」，padding 降为 xs（现状 is-idle 变体语义保留） |

## 4. TabPlate（页签板）

四页签（训练/仓库/成长/记录）的切换件；active/tree 态可见，idle 态裁掉。

### anatomy

横向 4 等分 grid（gap 2xs），每签：font-heading + 底部 2px 指示条（透明 → accent）。min-height：compact 2rem / 标准 2.5rem。容器下缘 1px border。

### 状态

| 状态  | 表达                                               |
| ----- | -------------------------------------------------- |
| 默认  | muted 文字 + 透明指示条                            |
| hover | text 文字，--motion-fast                           |
| 激活  | text 文字 + accent 指示条，激活切换 ≤--motion-base |
| 聚焦  | accent 2px 外描边（focus-visible）                 |
| 禁用  | opacity 0.45，不响应（预留，当前四签无禁用场景）   |

### 键盘

左/右方向键在签间移动，Home/End 跳首尾；`role=tablist/tab/tabpanel`，激活签 `aria-selected=true`（a11y 细则在 Stage 3 补全）。

## 5. 组件与模式的裁剪关系

| 组件      | active | idle                      | tree |
| --------- | ------ | ------------------------- | ---- |
| SkillRow  | ✓      | 裁                        | 裁   |
| IconSlot  | ✓      | ✓（sm 角标 + md 暂停键）  | ✓    |
| StatusBar | ✓      | 变体为迷你窗文本列+进度条 | ✓    |
| TabPlate  | ✓      | 裁                        | ✓    |

裁剪一律 `display:none`，不卸载组件（`产品形态.md` §4）。
