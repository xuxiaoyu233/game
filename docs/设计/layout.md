# 布局规格：训练页 active/idle 两态

更新日期：2026-10-17。约束与窗口数值见 `产品形态.md`；本页给区域级布局表与面积分配。布局算术统一约束：**固定区之和 + 滚动区最小可见高度 ≤ 窗口高度**，滚动区不参与加总。单位 px（1rem=16px）。

## 1. 训练页 · active 态

### 1.1 区域分解（所有宽度档共用）

| 区域        | 类型   | 高度依据                          | 内容                                     |
| ----------- | ------ | --------------------------------- | ---------------------------------------- |
| 场景/极光层 | 固定层 | 全窗垫底                          | 时代场景图 + 极光，不遮挡交互            |
| header      | 固定   | 37.6（2.35rem）+ margin 6.4       | 产品名、时代徽记、模式切换入口           |
| StatusBar   | 固定   | ≈52                               | 当前活动、进度条（6）、速率、暂停        |
| TabPlate 栏 | 固定   | ≈36                               | 训练/仓库/成长/记录                      |
| 面板滚动区  | 滚动   | 剩余全部                          | ReturnReportCard + SkillGrid/SkillDetail |
| SaveMenu    | 固定   | ≈48（compact 档允许压到一行 ≈38） | 保存/导出/导入                           |

### 1.2 宽度档布局表

| 档位            | 窗口宽  | 面板布局                                              | 关键数值                                                      |
| --------------- | ------- | ----------------------------------------------------- | ------------------------------------------------------------- |
| compact（基档） | ≤380    | 单列；活动卡 2 列网格                                 | 卡 min 156×2 + gap 6.4 + 壳 padding 22.4 = 341 ≤ 360 ✓        |
| 标准（≥381）    | 381–719 | 单列；活动卡 2 列网格，标准间距                       | 壳 padding 0.7rem                                             |
| 双列（≥720）    | 720–959 | 主从双列：左技能列表，右技能详情                      | 左列 232 + gap 12.8 + 右列 min 400 + padding 45 ≈ 690 ≤ 720 ✓ |
| 三列（≥960）    | ≥960    | 左技能列表 + 中详情 + 右上下文栏（升级建议/记录摘要） | 232 + 400 + 232 + gap 25.6 + padding 45 ≈ 935 ≤ 960 ✓         |

### 1.3 纵向预算验证（min 360×480）

chrome 184（算法见 `产品形态.md` §2.1）+ 滚动区最小可见 4 行 × 56 = 224 → **408 ≤ 480 ✓**，余量 72 分配给 ReturnReportCard 首行。

最长列表场景：金工 18 活动 × 56 = 1008，全部在滚动区内，不影响 chrome；选中技能后 SkillDetail 的头部（技能名/等级/经验条 ≈ 96）进入滚动区顶部，不在固定区。

## 2. 训练页 · idle 态（迷你窗）

### 2.1 面积分配（唯一信息结构，禁止增删）

```
┌──────────────────────────────────────────────┐
│ [插画 64×64]  活动名（body 一行）        [⏸] │
│               ▓▓▓▓▓░░░ 进度条 6px       28×28│
│               速率（caption 一行）            │
└──────────────────────────────────────────────┘
总高 72 = 64 + 上下 padding 4×2
```

| 元素       | 尺寸            | 位置      | 内容来源                                                                |
| ---------- | --------------- | --------- | ----------------------------------------------------------------------- |
| 动作族插画 | 64×64           | 左，x=4   | 共用角色插画 + 时代背景（`assets/mini/`），左上叠 20×20 动作族 SVG 图标 |
| 文本列     | 宽 120–268 弹性 | 中，gap 8 | 行1 活动名 body；行2 进度条 --progress-height-md；行3 速率 caption      |
| 暂停键     | 28×28           | 右，gap 8 | 内联 SVG（暂停/继续双态），走现有 dispatch                              |

### 2.2 宽度算式

- min：4×2 + 64 + 8 + 120 + 8 + 28 = **236** ✓
- default：文本列 164 → **280**（活动名 + 速率两行中文最长场景不折行）
- max：文本列 268 → **384**；高度恒 72

### 2.3 行为约束

- 只读 + 暂停键为唯一操作；点主体（插画与文本列）回 active 态。
- 迷你窗无 chrome、无页签、无滚动区；布局算术：72 ≤ 72 ✓。
- 挂机进行中暂停键显示暂停图标，已暂停显示继续图标；进度条与速率照常更新。
- 常驻置顶、无边框依赖工程侧窗口能力（见 `产品形态.md` §5）。

## 3. tree 态画布布局

区域与算式见 `产品形态.md` §2.3 与 `树契约.md`：左栏树列表 152 + 画布（缩放 0.5–1.5、平移），顶栏为页签 + 面包屑。

## 4. 响应式实现纪律（规格约束）

- 断点只有 `产品形态.md` §3 表中五条；禁止新增像素级断点，新需求先改令牌或档位定义。
- 禁止 `max-width`/`max-height` 媒体查询；compact 样式是基档默认值，增强样式全部写在 `min-*` 查询内。
- 滚动只发生在"面板滚动区"与 tree 画布；header/StatusBar/TabPlate/SaveMenu 任何时候不滚出视口。
