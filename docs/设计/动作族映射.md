# 动作族映射（106 活动 → 15 族）

更新日期：2026-10-17。输入：`src/content/data/activities.json`（106 条，已逐条核对）。动作族是迷你窗插画与动作图标的归并单位；活动数据本身不带动作字段，本表是唯一映射来源，工程侧按本表生成常量，不改 `activities.json`。

## 1. 归并原则

- 按**动作语义**（角色身体在做什么）归并，不按技能归并；一个族可跨技能（如 `forage` 含 herbalism 与 farming 的采集动作）。
- 族数 15（约束区间 12–16）；每族活动数 3–11，无单成员族。
- 族 ID 用稳定英文 kebab-case 单词（内容 ID 约定）。

## 4. 核验方式

- 覆盖核验：本表 106 行与 `activities.json` 的 106 个 `id` 必须一一对应；工程侧可用一条脚本断言「每个 activityId 恰好出现一次」（验收条款见 `acceptance.md`）。
- 新增活动时，内容作者在本表追加一行；本表缺失即构建期检查失败。
