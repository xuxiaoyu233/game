## 本轮视觉决定

上一张蓝灰框线图仅保留为历史结构草稿，**不再作为 CodeBuddy 的视觉施工依据**。新的视觉方向是温暖的故事书小镇：画面占主体，纸色卡片承载阅读，绿色按钮只突出主要动作，麦金用于少量状态/边饰。去掉通栏的大资源卡与上下整块后台面板，桌面采用轻资源条、可收起的建筑卡和底部小导航。

| 部分     | 当前样稿                                                 | CodeBuddy需要保留                        |
| -------- | -------------------------------------------------------- | ---------------------------------------- |
| 场景     | 单屏院落、清楚屋顶/田垄/道路、暖光与水面形成层次         | 一个小镇持续发展，背景与真实设施分层     |
| 资源栏   | 六项紧凑直读、资源图标有统一线条和功能色                 | 原粮/口粮分开，真实库存/速率同源，不造数 |
| 建筑卡   | 场景局部图、名称、星级、产出、升级前后、费用与一个主动作 | 避免大段解释；具体阻塞可处理，详情可返回 |
| 导航     | 五个原有入口，图标/文字与选中态清楚                      | 只换展示，不停止生产或重置选择           |
| 发展选择 | 三张简明方案卡，主体/作用对象清楚，选中有边框反馈        | 这是C2候选样式，V2不提前上线规则         |

### 单一可编辑样式源

[styles.css](styles.css) 是本目录的颜色、尺寸和组件状态源，避免再手抄一套互不一致的 token。主要颜色为纸底 `#F8F0DD`、正文 `#403C2B`、辅助 `#6C654F`、绿主操作与麦金边饰；正文以14px起，标题使用本地中文衬线字体，功能文字沿系统无衬线。主要操作/弹窗关闭采用44px目标。具体对比核验见结果文件，不将关键色对通过扩称为整屏可访问性验收。

当前只核验 `1440×900` 与 `960×720` 桌面。目录里已产生的手机探索 CSS/截图保留原时点，**不属于本次交付范围，不要求继续修理或移植**；后续集成只取桌面规则。
