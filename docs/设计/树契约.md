# 树视图契约（Stage 1 草案）

更新日期：2026-10-17。范围：TreeCanvas / TreeNode / TreeEdge / TreeSidebar / TreeMinimap / TreeFilter 六件的 anatomy、数据契约、性能预算、树↔训练页导航模型。交互细则与验收条款留 Stage 3；本页数值为契约，不改可不行。

## 1. 数据契约

### 1.1 静态定义（内容层，新增 JSON，不进存档）

```jsonc
// TreeDefinition：一棵树一份
{
  "id": "tree-skill-mining", // 稳定 kebab-case
  "kind": "skill", // skill | tool-line
  "label": "采掘",
  "nodes": [
    {
      "id": "mine-common-ore", // 复用现有 ID 体系：activityId / toolId+level
      "x": 0,
      "y": 0, // 显式坐标（画布单位 px，缩放前）
      "ref": { "type": "activity", "id": "mine-common-ore" },
    },
  ],
}
```

- **nodes 显式坐标**：坐标是内容数据，由内容作者排布，不做自动布局；坐标单位 px，画布原点在左上。
- **requires 派生边**：边不存储，由规则派生——
  - 技能树：活动按 `requiredLevel` 升序成链，每个节点向「同技能内 requiredLevel 低于自己的最高节点」连一条边（数据源 `activities.json`）。
  - 工具线树：5 级节点顺序成链（数据源 `tools.json`）；升级节点（`tool-upgrades.json`）额外向「产出 requiredItemId 的配方所属活动节点」连一条跨树引用边（虚线样式，点击跳对方树）。
- 节点 ref 只允许两类：`activity`（106 活动内）与 `toolLevel`（5 线 × 5 级 + 20 升级）。禁止引用不存在的 ID，构建期校验。

### 1.2 状态派生（复用现有事实，不新增状态源）

| TreeNode 四态 | 派生规则                                                                       |
| ------------- | ------------------------------------------------------------------------------ |
| `locked`      | 前置未满足（技能：skillLevel < requiredLevel 且有前置 locked；工具：前级未到） |
| `unlockable`  | 前置全 unlocked，自身未解锁/未升级；工具升级另需仓库中 requiredItem 数量足够   |
| `unlocked`    | 技能：skillLevel ≥ requiredLevel（`engine.ts` 同一判定）；工具：已到该级       |
| `maxed`       | 技能：该技能全部活动 unlocked；工具线：Lv5                                     |

输入仅为：技能等级（存档现有）、工具等级（存档现有）、仓库数量（存档现有）、内容 JSON。时代不进树状态。

## 2. 六件 anatomy

### 2.1 TreeCanvas

画布容器：深底色（background）+ 网格点纹（1px dot，32px 间距，border 色 20% 透明度）；内部一个 transform 层承载全部节点与边。缩放 0.5–1.5（步进 0.1，滚轮/按钮/快捷键 ±），平移（拖拽/方向键），`transform-origin` 跟随指针位置。默认视图：纵向居中、横向对齐当前可解锁节点。

### 2.2 TreeNode

176×64，radius-md，surface 底：

```
┌──────────────────────────┐
│ [IconSlot 28] 名称(body) │  ← 活动名/工具级名
│              Lv 要求(caption) │  ← 「Lv 13」或「坯料 ×2」
└──────────────────────────┘
```

| 状态       | 表达                                                   |
| ---------- | ------------------------------------------------------ |
| locked     | muted 文字 + border 描边 + 锁形小图标（IconSlot sm）   |
| unlockable | accent 描边 + accent 文字 + 呼吸光环（≤--motion-slow） |
| unlocked   | tone 色描边 + text 文字                                |
| maxed      | accentSoft 底 + accent 文字 + 角标「MAX」              |

### 2.3 TreeEdge

SVG path，贝塞尔纵弯（同层间横向弯）；描边 1.75 与图标一致。locked 路径 muted 40% 透明度，已解锁路径 tone 色。跨树引用边：虚线（dasharray 4 4）+ 箭头。边不响应 hover，选中节点时其直接前后边 accent 化。

### 2.4 TreeSidebar

左栏 152px：树列表（12 技能树按技能顺序 + 分隔线 + 5 工具线树），每行：IconSlot sm + 树名 + 进度 caption（如 7/10）。当前树行 accentSoft 底。列表超高独立滚动，不影响画布。

### 2.5 TreeMinimap

右下角 120×80，radius-sm，glass 底：节点缩为 2×2 点（状态色），视口为 accent 描边矩形；点击跳转视口。出现条件：节点数 >300 或画布范围超过视口 2 倍。

### 2.6 TreeFilter

顶行 chips：全部 / 可解锁 / 未解锁 / 已满 + 搜索框（匹配名称）。过滤只降透明度（非命中 15%），不删节点、不改坐标，保证布局稳定与性能预算成立。

## 3. 交互契约（细则 Stage 3）

- 缩放 0.5–1.5；平移无边界回弹，越界 clamp 到画布包围盒 + 20% 余量。
- 键盘可达：Tab 进入画布后方向键在节点间移动（沿边），Enter 激活，Esc 返回侧栏。
- `F` 聚焦当前可解锁节点：居中 + 缩放归 1，动画 ≤--motion-slow。
- 节点点击 = 选中（详情气泡：名称/要求/产出/跳转按钮）；双击或气泡按钮跳训练页。

## 4. 性能预算

| 规模      | 策略                                                                      |
| --------- | ------------------------------------------------------------------------- |
| ≤300 节点 | 全部直出（DOM 节点 + SVG 边）                                             |
| >300 节点 | 视口裁剪：仅渲染视口 + 1 屏余量内的节点与边；坐标显式所以裁剪是 O(1) 过滤 |
| 通用      | 缩放/平移只动 transform 层；TreeFilter 不改树结构；重渲染防抖到帧         |

当前内容规模估算：单技能树最多 18 节点（金工），工具线 5+4=9 节点；若后续出"全技能总览树"（106 活动 + 45 工具节点 ≈ 151）仍直出，>300 预案为后续多树合屏预留。

## 5. 树 ↔ 训练页导航模型

- **进入**：active 态左栏（双列档起）或训练页 SkillDetail 头部「查看树」按钮 → tree 态，TreeSidebar 选中该技能树，画布聚焦当前可解锁节点。
- **返回**：面包屑 `训练 / 树 / {树名}`：点「训练」回 active 训练页并保留原选中技能；点树名无操作（当前位置）。
- **互跳**：树节点「去训练」→ active 训练页并选中对应技能（复用现有 `selectedSkillId`）；训练页选中技能变化不影响树的选中状态，两者独立记忆、切换后各自保留（`产品形态.md` §4）。
- tree 态常驻 StatusBar：挂机不中断，暂停键在树视图同样可用。

## 6. 边界（本轮不做）

- 不做自动布局、不做编辑器；坐标手工维护，构建期校验重叠与边引用。
- 不做节点自定义解锁条件类型；四态之外不新增状态。
- 不做小地图拖拽框选、不做多选；Stage 3 评估。
