## 7. 门禁与 CI 范围化模型

| 时机             | 命令                                                           | 说明                                                                                                                                                         |
| ---------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 阶段内小改       | `npm run test:area -- <区域>`、`npm run check:fast`            | 新增脚本：`test:area` 显式列各区域测试文件；`check:fast` = format:check + typecheck + lint                                                                   |
| 阶段末/批次边界  | `npm run check`                                                | 全套，定义不变                                                                                                                                               |
| 影响 UI/装配     | 追加 `npm run test:e2e`                                        | 定义不变                                                                                                                                                     |
| 影响 Rust/桌面   | 追加 `native-check`/`native-build`                             | 定义不变                                                                                                                                                     |
| CI：push         | 仅 `npm run check`                                             | 已落地（批 `ci-tiering`）：web job 只跑 check，windows job 与构建/e2e 步骤加 `if: github.event_name == 'pull_request'`；未限定分支名，避免集成分支改名后失效 |
| CI：pull_request | web job（check + build:web + e2e）+ windows job（桌面 + Rust） | 不变，合并前全集结                                                                                                                                           |

降级带来的硬约定：合回集成分支必须走 PR——push 不再跑 e2e 与原生，直接推会绕过全量把关。

PLAN 门禁措辞同步：阶段内定向、阶段末全套、PR 合并前全套（含适用原生/实机项）。

## 9. 风险与未决

- **与 P4-D-U3 的关系**：S1 不触碰 `SkillPrototypeApp.tsx` 内部结构；按页签拆件排在 U3 之后单独评审。
