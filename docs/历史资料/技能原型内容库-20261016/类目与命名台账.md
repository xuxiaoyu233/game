| 概念     | 玩家功能                        | 当前设计边界                                                                                   |

| 物品类目 | 方便查询用途                    | 原料/加工材料/工具部件/燃料/消耗品/通货/贵重品，不自动成为技能或货币                           |
| 工具提升 | 材料换长期效率                  | 五条工具线各 5 级（II–V）；无默认磨损                                                          |
| 商店     | 硬币换固定材料                  | `shopOffers` + `purchase` 即时命令；价格固定，不产生周期                                       |
| 消耗品   | 熟鱼换限时加速 buff             | 已实现：周期 ×0.87（快 13%）、30 分钟游戏时间、单一增益槽                                      |
| 燃料     | 木炭扩展离线上限                | 已实现：每份 +1 小时、封顶 +8 小时、离线结算时扣减                                             |
| 发展路线 | 看清下一步条件与用途            | 技能→活动/配方→工具/后续加工，从机械定义投影                                                   |
| 任务     | 已有材料/事实增加目标与叙事用途 | 后续短任务，不作为技能成长唯一通道                                                             |
| 仓库     | 数量、来源、用途和缺口          | 不先做容量经营                                                                                 |

## 命名规则

- 单纯显示变化改 themes 与台账，不改 ID/库存/行为。
- 意义、配方或库存模型变化按机械变更处理，审查 content/schema、冻结定义与显式迁移。
- 编辑/知识/人物 ID 与机械 ID 分开；别名只用于检索和展示，不推断奖励或解锁。
- 候选不能自动显示为锁定卡；只有来源、用途、门槛和实际内容都成立才进入玩家界面。
- 世界内别名在题材选定后由批准资料映射为展示；功能名先清楚说明用途。
