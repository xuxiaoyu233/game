整体背景、回响片段定义、开放副本框架和内容进入游戏的流程，统一见大背景与副本总框架。若总览与本文的作者真相细节不同，以本文为准；总览负责摘要和跨文档术语统一。

## 一句话故事与玩家身份

你是一名失忆的返航者，在连接失序世界的中转站醒来。你带队建立临时营地，从不同世界带回航标证据，逐步修复回家的坐标，也发现负责送你回家的值守员曾经阻止过你的返航。

长期目标是弄清“该回到哪里、谁在等待、返航会牺牲什么”。每一卷回答一个具体问题，解锁下一组世界。主空间不是结算菜单：同一位人物、同一份档案和一扇逐渐响应的门，持续承接旅程。

## 必须保持一致的世界规则

1. 世界是事故留下的“回响片段”，并非可随意修改的完整历史。林地、旧城、雪站可以属于同一次事故的不同年代，玩家进入顺序不代表时间顺序。
2. 驻守的你与四名队员是投影。营地失守会切断这次连接，安全返回主空间，失去未带回的物资与证据。当前永久积分、能力和已经归档的线索保留。剧情不把反复失败写成角色永久死亡。
3. 木石与建筑依附片段，无法搬入主空间。成功回归得到的积分是稳定航标后带回的能量；当前可用于兑换三项永久能力或研究准备工具。档案、坐标与记忆也能越过世界边界。
4. 主动校准航标会提前引出回响：玩家提前迎战更强的怪潮，减少采集时间；成功带回更多能量。当前额外积分在最终成功回归时兑现，失败或撤离不兑现。
5. 队员没有各自的背包和人物成长：目前四人是固定工作人口。后续若引入具名伙伴和伤亡，需要另设玩法合同，不能仅凭对白声称已经存在。
6. 离开桌面时，世界停在需要决定的危险节点。这是玩法中的可中断时间，不借剧情暗中增加离线伤害。
7. 自由文本或 AI 对话可以解释、建议与表现人物，不改变已成立的事实，不凭空授予资源、线索、免战或胜利；有后果的选择必须落在可验证的选项与规则命令上。当前是固定选项对话，尚无自由文本 AI 对话。

## 作者因果锚点：部分信息已由隐藏支线向玩家揭露

这些设定用于防止续写互相矛盾；可在制作对应章节前调整，已上线证据不能随意改口。要区分设定作者掌握的因果、游戏里出现的证据、角色解释和玩家能独立核验的范围。隐藏支线已经把“航标曾循环重启以救回某人”和“你不是第一次经过这里”写入 `time-loop-proof`；这使它们成为玩家可读内容，但目前来源是两条异常记录与岑的承认，并未独立证明操作者身份、重启次数或玩家过去的完整经历。

- 事故原本是一场航标返航实验。系统尝试在时间碎片中接回失散者，代价是反复重排片段、抹去部分投影记忆。
- 岑是最早一批返航者留下的值守投影。他掌握部分重启记录，但记忆也有缺口。他曾为避免一次错误返航而延迟开门，后来把找回某个人当成继续重启的理由。
- 玩家曾经来到这里。森林中以“岑”署名的警告是真实旧记录；隐藏支线把这段话与古城石碑并置，岑据此承认玩家不是第一次经过。玩家已看到这项说法，但 `“第一次返航”` 的准确含义及此前发生了什么仍可在后续章节中核验，不能新增矛盾去否认已归档的支线文字。
- 序章获得的第一段坐标只点亮出口的一格，不代表门已完整修复。雪站保存事故校时记录；之后需要核对返航对象与代价，才能开门。
- 世界能被重复进入，是系统重新连接同一片段；已归档证据不会因重入而抹去。重复任务收益属于经营循环，重大剧情事实只解锁一次。

### 新增森林支线：河岸测绘（首个可扩展玩法切片）

玩家可在进入森林前选择是否接“信号与河岸测绘”契约。守住第一波后发现河桥断裂：花费木石修复，可派一名队员测绘 45 秒；也可免费绕行，并放弃本局这项额外任务。派队期间队员不能同时贡献对应岗位的采集或守备，因此这是时间、材料和防线之间的真实交换。

项目完成后，队伍取得临时 `forest-river-record`。只有成功回归，它才会写入主空间档案并结算额外积分；失守或主动撤离不会保留本轮成果。测绘册指出河流地图通向一座“尚未建成的城市”，并要求回主空间核对。

### 当前已实现的返航分岔：观测坐标或救援补给

带回 `forest-river-record` 后，中转站的岑会把测绘册与旧城地图叠放核对。玩家必须在一次性对话中作出选择：

| 分支           | 永久主空间变化                                | 古城契约目标                                                   | 成功回归的证据                                      |
| -------------- | --------------------------------------------- | -------------------------------------------------------------- | --------------------------------------------------- |
| 追查观测站坐标 | 解锁“逆行观测站”；后续每局额外准备 4 石材     | 建避难棚、瞭望塔和一段围墙，守过三波；再造第二座塔可获可选奖励 | `ruins-observatory-record`：星图指向河流源头        |
| 保护撤离补给线 | 解锁“古城救援补给线”；后续每局额外准备 4 木材 | 建避难棚、两段围墙和伐木场，守过两波                           | `ruins-relief-manifest`：名册证明撤离队伍曾经过古城 |

选择记录、对话线索和开放契约都保存在永久主空间；古城里的木石、建筑、生命和怪潮进度每次重新开始，只有成功回归才结算契约积分与分支档案。首次选择决定当前契约和额外补给；成功完成所选契约并回归后，另一条契约开放供返场补齐，因此不会永久锁死内容。剧情事实只证明“路线存在”，不宣称幸存者已获救。两种契约继续使用现有通用建设与怪潮条件，没有引入新世界规则。当前机械内容为 12.0.0、存档 schema 7；v11 活动副本先按冻结 v11 规则补算再迁移，随机事件不授予未定义的永久故事事实。

这些节点、价格、工时与主次目标由机械内容定义，人物文案单独存放；本章维护因果与玩家读到的文字，不维护数值。当前仅森林使用这组可选契约和派队项目，古城与其他世界仍未接入这套支线。

森林与古城仍采用木石建设与怪潮基础规则；分支契约提供不同建设组合和阶段目标。雪站已实现独立环境模式，但没有实际救援 NPC、最终开门或结局。

### 当前隐藏支线：验证岑的说法

1. 森林守过第一波，选择修复烽火台，再消耗物资调查底座。得到临时 `forest-inscription`：警告不要相信第一次返航，署名残留“岑”。
2. 古城守过第一波，支付木石调查石碑。得到临时 `ruins-script`：航标主动重排世界，值守员记录被删。
3. 两份证据分别成功带回后，主空间可以交叉核对，获得永久 `time-loop-proof`。岑承认这里曾重启过，玩家曾经经过。

支线资源与防御建设竞争；调查后失败或放弃会丢失本次尚未归档的证据。当前支线提供更完整的信息，没有额外永久数值奖励，也不阻断主线。已经归档的线索保留。后续若让证据改变关卡，必须同时兑现对应配置和规则。

### 第一卷的收束规则

1. 本卷回答“片段顺序是否自然”：雪站证据应支持“不是”，但不应同时公布返航对象、玩家身份和完整代价。
2. 每次回归只回答当前世界所能证明的问题。岑的判断须标明依据，后续物证可以修正判断，不能推翻已经带回的原始记录。
3. 卷尾将“坐标可用”与“返航对象已确认”分开：玩家得到第二段坐标，但真实返航仍未完成。下一卷才围绕名单、对象和代价作选择。
4. 雪站的燃料/温度、发电机修复、节点和安全锚定已按受限环境模式实现并有规则/存档测试；实际玩家数值平衡与 Windows 窗口/托盘验收仍单独待做。

多站列车和镜像城区移为**第二卷候选**：列车可验证失散者名单及护送取舍，镜像城区可验证出口与岑的责任。它们不是第一卷必须同时生产的关卡。

## 首次、返场与中断反馈合同

界面反馈只承认现有档案能证明的事实，不编造世界访问次数。当前存档只有最近一次结算，不是完整旅程日志；因此“首次返航”指新的主线对话尚待处理，“返场”指相应的一次性选择已归档，不是显示精确的第几次进入。

## 如何持续扩展，避免只是换背景

长期扩展分为两条：固定章节负责答案与人物变化；重复任务负责不同经营目标和风险。通关后应允许“返场任务”：保留旧事实，新增不同目标、契约或调查，不每轮重复第一次见面的对白。

每个新世界必须交出以下七项内容：

1. 主空间为什么现在能进入这里，人物为什么要求玩家去。
2. 该世界独有的资源竞争或限制；至少一个决策不能由森林怪潮数值直接替代。
3. 可理解的基础回归条件与失败边界。
4. 至少一个有实际代价的额外目标，以及兑现奖励的条件。
5. 一条回答上一个问题的证据，以及一条通向后续世界的新问题。
6. 回归后人物、档案或入口发生哪项可见变化。
7. 再次进入为什么仍值得玩，哪些选择固定、哪些能重做，哪些剧情不重复奖励。

随机事件也要遵守因果：寒潮改变燃料需求，桥梁损毁改变护送路线，档案矛盾改变判断。不要只随机赠送或扣除资源，然后称为故事。

## 对话与内容制作边界

- 短对白服务桌面小窗：交代目的、冲突、可选行动；长记录放入档案，可随时收起。
- 河岸对话的二选一会开放不同古城契约并改变后续每局起步物资；选项效果使用规则 ID 校验。其他纯故事对话仍按各自合同生效。
- 第一波前的一次性建设路线属于**本局策略**，不等于永久剧情阵营。不能用选项文字暗示未来阵营锁定已经生效。
- 主线奖励来自任务事实，台词不能直接写积分。调查物资应在操作处显示并一次扣费。
- 小说和影视可以启发“主空间、契约、跨世界、回归、真相逐步揭示”的结构。当前采用原创人物、情节和世界，不把已有作品的名称、正文或角色立绘批量搬进关卡。

## 编剧核对清单

- [ ] 本世界回答了一个旧问题，而不是只增加谜语。
- [ ] 人物知道的信息有来源，隐藏真相与已公开证据不冲突。
- [ ] 基础回归、投影失败、真实返航三个概念没有混用。
- [ ] 任务要求可以由规则验证，玩家选项有实际成本或后果。
- [ ] 首次、返场、失败重试的文字不互相矛盾。
- [ ] “已上线”“规划”“作者真相”标记准确。

技术配套：世界包与叙事合同、副本资料库、本轮玩法规格。新剧情 ID 应稳定；中文对白只进入主题层，不能进入存档。
