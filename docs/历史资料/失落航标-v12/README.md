# 《失落航标》v12 历史资料库

> **资料状态：历史归档，不属于当前正史。** 归档对应旧版 v0.7.1、机械内容 12.0.0、存档 schema 7。它服务于旧版维护、来源追溯和创作复盘；不得将其中的人物、线索、路径、世界卡或机械 ID 直接描述为新版《诸界救援局》的设定或实现。

当前批准的正史与故事资料入口见[故事资料库总索引](../../故事资料库.md)和[《诸界救援局》故事与内容设定集](../../故事线设定集.md)。游戏规则和实际落地状态以当前源码、机械内容及[唯一主计划](../../../PLAN.md)为准。
