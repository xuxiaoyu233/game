## 断链与待办

- `keeper-sideproof` 已有 `forest-inscription` + `ruins-script` 前置并写入 `time-loop-proof`；其对话文字是岑的陈述，不是玩家独立验证的全部作者真相。世界卡与故事线设定集需继续保持这个置信层级。
- 四路径和 `BEAT-XC-01..04` 仍是作者资料候选，没有 TypeScript 投影或运行时内容映射。F-01 的 TypeScript 投影只覆盖当前游戏已有故事线索与档案文案，不会让这些候选进入 UI。
- `CHAR-CAND-*` / `REL-CAND-*` 仍是角色原型；固定节点上的独立行动、持久状态和存档迁移未实现。
- W-04～W-08 是候选世界；W-06～W-08 只有叙事卡，未完成具体地区/年代素材研究、规则合同或游戏验收。
- 交叉索引仍是 Markdown 人工维护；自动校验只覆盖故事档案投影中的线索、来源世界/对话和文案引用，不检查整张索引的 `Q-*`、`W-*`、`PATH-*`、人物关系和来源边。

## 增量更新规则

新建关系时填写起点 ID、受控关系词、终点 ID、前置条件、叙事状态、实现证据路径；若某一端暂时没有 ID，先登记为待建记录，不在不同文件里各自造一个别名。关系状态要与代码和当前验收记录相符。修改后同步回链到对应资料卡，并检查悬空引用和失效条件。
