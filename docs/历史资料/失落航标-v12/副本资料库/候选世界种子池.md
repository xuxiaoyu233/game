## 选种子的过滤规则

- 和现有世界相比，至少在局部规则、冲突来源、证据形态、玩家选择之一上有实质差异。
- 能写出玩家亲自核验的证据，不把关键真相只放在 NPC 长篇解释里。
- 给重复剧情骨架留下明确落点，并能说明本世界带回什么；不能靠“世界很奇怪”独自成立。
- 运行时突发事件只能在稳定世界事实上增加压力或新证据，不得突然撤销已经成立的因果。
- 涉及新数值或行动的点子先标成机械需求。未进入 `src/content` 并通过 domain 校验之前，仍是文字候选。
- 参考小说只取类型组织问题，不挪用原作人物、地点、台词、怪物、关卡、谜题和标志性机制。
