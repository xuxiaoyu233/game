## 路径问题

当事件只被少数人经历、无法稳定复现，而且当事人可能遭受污名时，社会如何保存证词、评估风险并决定是否行动？本路径把灵异题材当作有待核验的世界现象和社会经验来写；各世界可确定异常规则，但档案中的解释仍可能彼此冲突。

## 演变节点

| 节点                          | 原有难题 → 新方法与组织                                                                       | 获得的能力                                 | 代价、失效与后续问题                                                                   |
| ----------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------ | -------------------------------------------------------------------------------------- |
| `BEAT-PATH03-01` 传闻与见证   | 个别家庭遇到重复声响、失踪或地点禁忌，彼此不信任 → 由亲属、行旅者、讲述者和地方仪式保存异例   | 传闻、路线、季节和人际关系提供早期风险地图 | 口述会改变，名誉和权力影响谁被相信。没有文字不等于没有知识；谁被排除在共同记忆之外？   |
| `BEAT-PATH03-02` 证词与档案   | 迁徙、城镇和司法机构扩大后，孤立故事难以比较 → 出现见证簿、调查问讯、巡行人员及相互冲突的记录 | 能比对时间、地点、证人关系与异常触发条件   | 官方登记会压低非精英声音，也可能把未解决事件定性为欺诈、疾病或犯罪。记录由谁保管？     |
| `BEAT-PATH03-03` 异常治理网络 | 远距社会和自动化系统处理大量异常报告 → 组织建立局部隔离、复核、撤离和公开标准                 | 能在未解释真相时限制损害并协调响应         | 分类误差会造成大规模误伤；标准本身也会成为人们利用或对抗的规则。更高技术并不会消灭未知 |

失败支线：机构因要维持可信度而删除无法解释的证词；被删记录转由口述网络流传。后来者得到更多线索，却必须判断复述、暗示和原始见证之间的差异。

## 证据、玩法与跨路径接口

- 每条异常记录包含观察者、时间/地点、可重现步骤、相反证词、已采取措施和未能排除的解释。
- 副本玩法可以让玩家选择复测、保护证人、暂时封锁地点或公开未定结论；每个选择承担不同的风险和信任后果。
- 与 `PATH-01` 科技路径交叉时，仪器能限制误差范围，却不能单凭信号将未知归类为“无事发生”。
- 与 `PATH-02` 神学路径交叉时，仪式可构成可观察行动与共同体规范；其宇宙解释仍独立标注。
- 与 `PATH-04` 修行路径交叉时，个人身体经验可以成为证词，但不能未经同意当作公共样本。

## 来源边界

`SRC-42` 研究早期现代英格兰幽灵故事、口述见证和权威如何形成；它说明如何书写社会记录，不证明鬼魂存在。`SRC-43` 强调口传对知识、价值与集体记忆的作用。作品中的异常规则必须由本作证据定义。

## 文学结构参考与阅读范围

结构上采用“一个人的异常经验被他人质疑—证词进入记录制度—制度因证据不足/权力压力排除某些声音—被排除者形成替代记录网络”。`SRC-01` 仅为官方作品简介，`SRC-05` 仅为两段章节片段；它们只提示局部规则、阶段回归与长线谜题如何并行，不代表完整作品结构。历史和方法材料以 `SRC-42` 研究摘要/可见章节、`SRC-43` UNESCO 官方说明为边界，且不据此断言超自然实体存在。
