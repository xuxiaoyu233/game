## 路径问题

个体怎样通过练习改变感知、耐受、判断和行动？知识如何在师徒、家族、寺观、学派或公共机构中传承？修行不是人人争夺境界名次的统一等级表，也不代表历史上的修炼记载是现代实验验证的自然科学事实。奇异能力若在某个原创世界确实存在，须由该世界可观察、可重复或可争议的证据来建立。

## 演变节点

| 节点                              | 原有难题 → 新方法与组织                                                                       | 获得的能力                                     | 代价、失效与后续问题                                                                                 |
| --------------------------------- | --------------------------------------------------------------------------------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `BEAT-PATH04-01` 日用养护         | 疾病、疲劳和环境暴露多依赖个人经验 → 家庭、照料者与行旅传统保存饮食、呼吸、动作和草药实践     | 形成因季节、身体和生活环境而异的经验知识       | 方法可能不适配他人；照料责任常被分配给特定群体。谁承担练习与失败的成本？                             |
| `BEAT-PATH04-02` 传承与门径       | 经验难以教授、核对和保护 → 师徒、谱系、场所、戒律、经典和共同练习建立入门、验证与传承         | 形成高度专门的知识、共同体支持和长期训练路线   | 传承边界能保护方法，也能垄断资源；门槛可能维护安全，也可能服务权力。谁能成为证人或继承人？           |
| `BEAT-PATH04-03` 身体与制度再协商 | 现代医疗、工业和计算系统重塑身体训练的环境 → 修习者与公共机构就测量、隐私、疗效和介入边界协商 | 个人方法可进入新型照护、远距合作或复杂环境适应 | 量化指标可能抹平个体差异；技术介入会产生依赖、不可逆改变和身份争议。能力提升后，谁有权要求继续使用？ |

失败支线：组织只承认可量化的训练结果，排除无法适配标准的人；另一条支线因保密而失去交叉复核，传承变为个人依附。两者分别付出排斥与不可验证的代价。

## 证据、玩法与跨路径接口

- 角色卡记录“练习者报告、可观测变化、外部复核和不适用条件”四栏；不得把其中一类证据替代其他三类。
- 副本选择可在个人修习、共享传承与公共医疗/技术支持之间权衡，体现机会、授权和身体代价。
- 与 `PATH-01` 科技路径交叉时，工具扩展测量能力，也可能把训练数据与身份绑定。
- 与 `PATH-02` 神学路径交叉时，修习可承担共同伦理或礼仪责任，但两者仍有不同的传承和验证方式。
- 与 `PATH-03` 灵异路径交叉时，个人经验可能先于公共解释出现；记录前要尊重当事人同意。

## 来源边界

`SRC-41` 讨论道教思想、文本、宗教组织和修习传统的历史变化；它不把所有传统归结为单一体系。`SRC-43` 支持记录社区传承者与知识实践的方法。文学里的修仙等级、灵气数值和突破规则只属于作者原创机制，不能回写为历史事实。

## 文学结构参考与阅读范围

结构上用“个人实践产生报告—师承/共同体检验其边界—扩大传播带来资格与隐私冲突—实践者可修正、退出或拒绝被量化”的行动链；成长以方法、关系与代价变化表现，不以等级表替代人物。`SRC-01` 只看官方简介，`SRC-05` 只看两段公开章节片段，仅提出任务、准备、回归与后果的组织问题，不代表通读修仙文学。历史依据 `SRC-41` 为相关条目、`SRC-43` 为官方说明；现代疗效或超自然事实不由这些来源支持。
