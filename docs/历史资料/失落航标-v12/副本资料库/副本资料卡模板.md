## 一致性与验收

- [ ] 名称与本库索引、设定集一致。
- [ ] 分开标注事实、人物推断和候选猜测。
- [ ] 文案没有许诺不存在的 NPC、规则、奖励或选择后果。
- [ ] 基础回归、附加证据、失败和撤离的结算互不混淆。
- [ ] 关闭桌面后不会暗中增加风险。
- [ ] 每条跨局变化都映射到可保存的事实和可观察回应。
- [ ] 引用只作结构研究，没有挪用原作场景、角色、台词或专有设定。
- [ ] 世界卡与复用骨架分开；组合不会只交换地点名称。
- [ ] 运行时可生成文本有本地兜底，且不控制数值、选项效果或存档结算。
- [ ] 文档标签准确区分“已实现”“已验证”“待验收”。
