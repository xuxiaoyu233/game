## 长线主谜题与首卷推进

跨世界连续性由“救援任务是否被正确登记”串起，而不是每一局临时换一个谜语。首卷的关键问题按固定条件逐步推进：

1. **首个任务：** 系统写着“已接回”，失籍城的求援仍在继续；成功回归带回的原始登记纸比系统多出一个住户栏。
2. **返场复核：** 玩家可以选择保护原始纸本或重建现场锚点，两条路线改变后续起步策略，但都可开放另一条复核委托。
3. **跨世界线索：** 后续世界会出现相同的注销格式或审计印记。此内容留作以后新增世界的接口，不在第一切片提前授予。
4. **卷内阶段答案：** 第一卷后段回答“系统为何会把未完成的任务记成成功”，但暂不公开操作者、被删者去向和救援局最初建立原因。

事实、推断和未知分别入档。主线线索只能由固定任务条件获得；随机事件仅能推进支线或补充材料，不能替代主线步骤。失败不会抹除已经永久归档的证据；未带回的临时发现可通过返场任务重新取得。

## 首个世界玩法：界锚、经营与救援路线

失籍城被周期性的“界潮”冲击。**界锚稳定度**从明确的初始值开始，按固定阶段规则变化；建造锚塔、投入锚材或提前压线会产生明确可预览的影响。稳定度影响可调查区域、额外目标和撤离成本；它不会随机处决队员，也不会因随机事件缺席而阻塞主线。达到最低撤离要求后可安全回归，继续探索需先确认机会成本。

| 路线       | 经营重点                                   | 取舍与可见结果                                         |
| ---------- | ------------------------------------------ | ------------------------------------------------------ |
| 稳固撤离线 | 生产能芯与锚材，建设避难区和防线，稳定界锚 | 资源优先保主目标，容易守住常规撤离门槛，支线资料较少   |
| 现场审计线 | 调一名队员调查缺页街区或复核人口纸本       | 调查期间少一份生产或守备；可带回支线证据并开放返场任务 |

所有基础目标在不手动采集的情况下均可完成。手动采集仅用于短缺补足；提前迎战、事件选项、研究与兑换分别改变时间压力、材料分配和下一局准备，不能只叠加免费倍率。局内能芯、锚材、建筑与未锚定成果都是临时状态；永久界点和已带回证据只在结算确认后进入总台。

## 事件与行动条款样例

每局最多出现一个随机现场异动。候选由世界、委托、阶段和既有选择筛选；运行时保存种子与抽选结果。所有按钮显示固定成本、人数影响、结果和证据条件。

| 事件           | 类型、触发和因果                                   | 选择与确定结果                                                                                                                             |
| -------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 第七环锚塔失稳 | 固定主线节点；界潮后锚塔结构松动，说明世界独有规则 | **优先抢修锚塔**：消耗锚材，稳定度恢复较多；**启用备用锚**：消耗能芯，恢复较少但留更多锚材；两种选择都可继续基础救援                       |
| 空屋里的求援灯 | 随机支线；登记为无人居住的街区仍有灯光与能耗       | **派队核查**：占用一名队员并花能芯，完成项目可带回“住户灯号记录”；**拆取电芯**：获得固定能芯，不得该线索；**保持现场**：无成本放弃本局调查 |
| 多出的一页户籍 | 随机支线；现场纸本人口比局内终端多一栏             | **封存纸页**：花锚材并派审计队员，完成项目可带回“缺页户籍副本”；**拆取锚钉**：获得固定锚材并放弃副本；**暂不取证**：无成本放弃本局调查     |

| 行动条款     | 故事来源                           | 候选局前效果                       |
| ------------ | ---------------------------------- | ---------------------------------- |
| 临时拨款冻结 | 救援局只能调拨最低应急库存         | 开局能芯与锚材各减少 25%，难度值 1 |
| 界潮提前     | 天文台修正了界潮窗口，准备时间变短 | 准备/阶段时间缩短 20%，难度值 2    |
| 锚点暴露     | 高强度锚信号会吸引界潮生物         | 威胁强度提高 15%，难度值 2         |

条款可组合，按成功完成基础委托的难度档位发放一次奖励。数值是提案初值，后续用路线推演校准；档位奖励不改变被批准的故事事实。
