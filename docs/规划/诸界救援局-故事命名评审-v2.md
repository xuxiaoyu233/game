## 第一世界与完整游玩因果

寰门调度站收到一份已被系统标成“全员接回”的求援委托。原始台账里没有呼号和世界编号，但频道仍重复播报：“零号月台还有人，请不要关闭回程线。”陶既明按正式记录派队复核，宋知微提醒玩家把系统时间、站台广播和现场凭证分开记录。首轮成功回归证明“已接回”结论与现场证据冲突，不回答谁改了记录、为何改写，也不确认呼救者最终去向。

零号月台的独有规则是**回程线路完整度**。固定脉冲会降低完整度；修复道岔、加固中继或抢闸接敌会以确定公式改变它。完整度决定支线能否定位和额外回执质量，但不会随机杀死队员，也不能让主线因为未抽中事件而不可完成。玩家可以稳住轨道和防线，也可以派人离岗调查无编号车厢，牺牲短期产量或守备换取可选证据。

一次任务按以下体验闭合：

1. 首次简报呈现“系统已结案、频道仍求救”的矛盾，直接进入教学委托；回访玩家看到上次回执与下一步复核入口。
2. 局前选择电芯/轨材补给与可组合行动条款；同屏说明基础目标、脉冲规则、可选目标和资源重置。
3. 队员自动生产并可调度岗位；建设轨道维修设施、临时避难区和防线。手动采集只补短缺，不是基础通关条件。
4. 到达危险节点后按常规准备，或抢闸接敌。点击前展示奖励、提前到来的压力和确定性损耗。
5. 固定剧情节点负责主线证据。满足条件时最多出现一条种子事件；事件暂停推进，等待玩家选择并展示成本、人员占用和结果。
6. 基础回归目标达成后，玩家选择立即回归或继续已解锁的调查。继续路线显示额外机会成本。
7. 只有成功回归才把线索写入回执档案、结算界点并清理副本资源。失败或撤离明确列出保留与未带回内容。
8. 宋知微按已归档证据更新“已证实 / 推断 / 未知”；返场委托可补做错过的支线，不重复发放已领取奖励。

## 事件与行动条款样例

随机只决定遇到哪条合格的已写事件。选项的资源消耗、人员占用、目标解锁和证据结果固定；随机池不提供主线唯一线索，不暗骰损伤或离线失败。

| 事件               | 触发与故事作用                                   | 候选选项及固定后果                                                                                                                                                |
| ------------------ | ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 道岔失灵（固定）   | 第一段脉冲后必达节点，教会玩家完整度和维修       | **抢修主线**：消耗轨材修复主线道岔；**切换维修线**：消耗电芯启用备用线路，完整度余量较低；两条路径都能完成基础回归                                                |
| 无编号车厢（随机） | 首次脉冲后合格入池；广播源指向不在图册中的车厢   | **派队测向**：消耗电芯并占用一名队员，完成调查项目后可带回“车厢录音”；**加固站台**：消耗轨材，改善当前防守/线路，不得到该线索；**暂不进入**：零消耗，放弃本局调查 |
| 倒序到站牌（随机） | 首次脉冲后合格入池；纸本签收时间晚于系统撤离时间 | **比对纸本**：消耗轨材并占用队员，完成项目后可带回“重复签收页”；**拆取备件**：获得固定电芯，放弃纸本证据；**封存现场**：零消耗，保留本局原状                      |

| 行动条款   | 世界内来源                 | 候选效果                           |
| ---------- | -------------------------- | ---------------------------------- |
| 无拨款出勤 | 调度站只批准基础物资       | 开局电芯与轨材各减少 25%，难度值 1 |
| 缩短停靠   | 车站窗口比预报更短         | 准备/阶段时间缩短 20%，难度值 2    |
| 高鸣追猎   | 过强的求援信号引来断层威胁 | 威胁强度提高 15%，难度值 2         |

条款可组合，奖励仍按难度档位和成功基础回归条件结算一次。数值是开工候选值，需经路线推演校准；玩家每次选择前看到实际效果，不将候选参数当作已验证平衡。

## 后续协作与落地边界

- 审核通过的故事设定和交叉索引成为新正史唯一来源；当前《失落航标》文档和 v12 活动内容先归档，不提前覆盖。
- 每个事件/对话/线索有自己的 ID 与来源关系；实现合同写入 `src/content`，规则后果写入 `src/domain`，展示文本和主题写入 `src/themes`。文档检查验证 ID 唯一、关系有效、内容可达和本地链接。
- 每个世界可有独立纯规则模块，但共用唯一运行时、命令队列、保存队列、离线决策停点与结算边界；不做任意脚本执行器或运行时 LLM。

- 新版集中验收 `check`、E2E、Web/desktop 与适用的 native 门禁；覆盖两种路线、稳定随机、回归不重复结算、v7 拒绝不改档、420×600/360×480，以及三轮无引导试玩。旧版验证只对隔离数据副本进行。
