## 2. 故事提案：第一卷《名册之外》

### 故事钩子

界桥中枢收到一条没有呼号、没有世界编号的求援信号。救援局的正式记录却显示：信号源所在站点早已完成撤离，求援人已被登记为“成功接回”。频道里传来的最后一句话是：

> “我们还在这里。别把整座站写成已经接回。”

值守官沈照按流程把任务归为“记录冲突”，档案核查员闻策则指出：系统里不存在这条信号的原始登记。玩家作为新任界外执行员，接下第一份复核委托。第一世界的目标是救稳中继、维持撤离窗口并带回现场回执；首轮只证明“登记结论与现场证据矛盾”，不揭示谁删了求援者，也不确认玩家与旧任务的关系。

### 角色关系

| 角色             | ID                              | 当前可知信息与职责                                             |
| ---------------- | ------------------------------- | -------------------------------------------------------------- |
| 沈照，值守官     | `character-shen-zhao`           | 提供委托、解释组织流程；他相信归档规则，但不替玩家否认现场证据 |
| 闻策，档案核查员 | `character-wen-ce`              | 对比回执、时间戳和名册；只提出证据能支持的问题                 |
| 无名呼救者       | `character-unregistered-caller` | 身份未登记；呼号、人数与生死状态暂不确定，不在开局揭底         |
| 玩家             | `character-field-operative`     | 玩家自定义呼号的界外执行员；背景真相留白                       |

角色台词只描述其实际知道的事实。局外档案标记“已证实 / 推断 / 未知”，避免随机事件或对话越权补写世界真相。

### 第一世界：静默潮汐带·坠灯港

坠灯港是建在潮汐断层边缘的转运站。每次“静默脉冲”都会压低无线电回波，站内留下持续生产的炉台、临时防线和被匆忙撤离的痕迹，却没有能与玩家直接对话的幸存者。救援对象是否被接走，必须由回归回执而非气氛文字判断。

本世界的独有机制是**回波完整度**：脉冲阶段会按固定规则损耗；修复中继、投入资源或抢先接敌会改变接下来的完整度。它影响支线信号是否可定位和额外回执质量，但不暗骰角色死亡，也不让随机事件决定主线能否通关。主目标始终可完成；玩家可在“稳住中继与防线”及“派人追查微弱回波”之间分配同一批燃料、结构件和队员。

| 局内选择   | 稳健路线                             | 调查路线                                         |
| ---------- | ------------------------------------ | ------------------------------------------------ |
| 队员安排   | 燃料与守备岗位优先，稳定跨过两个脉冲 | 调查员离开生产/守备岗位，短期少产出或少防御      |
| 资源投入   | 先修中继、建庇护所和边界设施         | 用结构件定位第二声部，保留较少的防御余量         |
| 迎战策略   | 按准备节奏迎战，保持回波             | 可抢先接敌换取“快速响应”奖励，但脉冲压力提前到来 |
| 可带回内容 | 主线现场回执                         | 主线回执，加上满足条件的可选录音或名册副页       |

资源仅在任务内使用；成功回归后未锚定的燃料、结构件和建筑清空。界点与已验证证据进入中枢。早战奖励、难度奖励和证据都按结算条件实际发放，局前只显示预估。

### 一局从进入到返场

1. **抵达中枢：** 首次进入由沈照说明“登记显示已接回，频道仍在呼救”的矛盾，直接开始引导委托；老玩家先看上次回执和下一项复核目标。
2. **局前准备：** 选择坠灯港委托、燃料或结构件补给、至多若干加压条款；同屏说明基础目标、回波规则、预计奖励、可能损失和临时资源重置。
3. **经营推进：** 自动生产燃料与结构件；玩家调度队员、搭建设施、修复中继。缺口可手动补采，但基本目标不依赖连续点击。
4. **接敌决策：** 按常规时间迎战，或选择抢先接敌。按钮前显示提前获得的响应奖励及波次提前造成的压力；压力按固定公式计算。
5. **处理现场异动：** 条件满足时，每局最多出现一条受种子控制的已编写异动。事件暂停等待玩家，成本、人员占用、结果和可得证据全部先展示。
6. **决定回归：** 主目标完成后，立即回归可安全结算；也可继续挑战已解锁的调查目标。不可逆的继续行动要先显示额外机会成本。
7. **回执结算：** 成功回归才归档主线证据与符合条件的支线证据、发放界点并清理副本临时状态。撤离或失败清楚展示保留、锚定与未带回内容，不能重复发奖。
8. **中枢返场：** 用界点兑换改变下一局策略的永久能力；闻策根据已归档证据更新“已证实 / 推断 / 未知”，并开放可补做的复核委托。未抽到的支线以后可返场补齐。

## 3. 事件与加压条款：故事因果样例

所有事件都由内容定义世界、章节、阶段和候选条件；seed 只决定本局遇见哪条合格事件。选项结果固定、可验证且在点击前展示。支线线索由任务规则授予，并且仅在成功回归后永久入档。随机不新增主线事实，不直接随机扣血、毁坏存档或授予胜利。

| 事件 ID / 名称                        | 出现条件与故事作用                                                   | 固定选项及结果                                                                                                                                                                                               |
| ------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `event-unlisted-shelter` 无编号庇护点 | 坠灯港首个脉冲后进入随机候选；现场有未登记的第二段求援回波           | `option-triangulate-shelter`：付燃料与结构件，启动测向项目，成功后可带回“第二声部录音”；`option-reinforce-relay`：消耗结构件增强当前回波/防守，不得支线录音；`option-leave-shelter`：不花资源，放弃本轮定位  |
| `event-reversed-rollcall` 倒序名册    | 首个脉冲后进入随机候选；实体名册的签收时间晚于系统中的撤离完成时间   | `option-compare-carbon-copy`：付结构件并占用一名调查队员，完成项目后可带回“重复名册副页”；`option-salvage-binding`：获得固定燃料但销毁可比对副页；`option-seal-rollcall`：不花资源，保留现场原样但本轮不取证 |
| `event-relay-blackout` 中继失明       | 主线固定阶段节点，不进入随机池；让玩家首次明确看到回波损耗和修复入口 | `option-restore-relay`：消耗资源修复，维持中继并继续主目标；`option-switch-to-beacon`：消耗不同资源，转用备用信标并承受较低的回波余量。两路都保留主线通关路径                                                |

事件只抽取一次并随运行存档；重载不重抽。选项造成的损失来自玩家明确选择的成本，或在选择前展示的确定性公式。支线事件没有抽中或选择放弃，都不会锁死主线。

| 加压条款 ID / 名称                      | 世界内来源                         | 局前可见效果                         |
| --------------------------------------- | ---------------------------------- | ------------------------------------ |
| `modifier-unfunded-dispatch` 无拨款派遣 | 中枢只批了最低限度的救援预算       | 初始燃料与结构件各减少 25%；难度值 1 |
| `modifier-short-tidal-window` 缩短潮窗  | 坠灯港的静默脉冲提前，准备窗口缩短 | 准备/阶段时长减少 20%；难度值 2      |
| `modifier-hunter-beacon` 追猎信标       | 高频回波吸引断层中的威胁           | 威胁强度提高 15%；难度值 2           |

条款可组合；总结难度值按既定档位结算一次奖励，前提是成功完成基础救援委托。UI 同时显示条款来源、效果、风险和兑现条件。后续世界可以用自己的组织限制与环境危险提供条款，不复制坠灯港文本换皮。
