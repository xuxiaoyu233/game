# 文明式放置沙盘：产品路线与扩展规格

> 2026-10-20范围修订：固定场景逐步完善的舒适放置经营取代强制持续开拓。本文文明式科技/时代保留为参考；择向扩地/邻接与致死环境不作为下一阶段前置，生存/PvE为后期自愿挑战。实际活动路线只见根PLAN。

日期：2026-10-18。本文定义完整产品方向、扩展内容和模块依赖，供根 [PLAN](../../PLAN.md) 调度；不维护第二份阶段状态。首版实施合同仍为[发展沙盘首版规格](发展沙盘首版规格.md)。用户最新要求：参考文明系列的沙盘与发展选择，同时始终是点击放置游戏。

## 产品定位与体验主线

玩家经营**同一个持续存在、向周围扩建的营地**。这是用户对多沙盘问题的最新选择，替代此前分区标签/多营地建议。点击负责选址、建设、等级提升、升星、研究与拓地；采集、加工、施工和离线推进自动完成。地图由小变大，生产链逐步延长，建筑结构和时代变化能直接看见；后期自动防御为建设提供用途。

基础循环：可选点击协助/选择下一目标→观察材料/空间/能力→建设与调整生产→自动积累→研究/扩地/等级或星级→地图变化。按用户最新问题补小额直接采集，具体白名单/收益/共享节奏只见首版规格；自动收入和离线结算仍无需逐块收获或点击领取。完整F01–F18功能与长期原36＋民生6候选见[产品目录](产品功能与科技目录.md)。最新生存与事件规则见[专门合同](生存经营与事件体系.md)，取代本文旧版将人口完全排除、天气只到D4才做的限制。

首版打开时应同时看见土地、四资源、时代与一个下一目标。点空地出现可建内容和费用，点建筑出现等级、投入/产出、库存/容量、自动等待原因与升级，点锁区出现解锁条件。科技页解释前置与效果，不成为新的刷经验页面。目标建议不强制固定操作顺序，木/石基础链的防死锁限制除外。

### 文明式空间选择如何保持轻量

首版只保留资源适建与有限空间；相邻额外加成放到金属发展阶段。建议首批仅两条：木工坊邻伐木场、铁工具坊邻铁矿，每个相邻有效设施给该加工设施 +10% 产出，最多两邻合计 +20%。这是待调参建议，不是原作数值。

加成从六邻和当前已建成设施派生，升级期间按现有建成等级识别；不把计算结果写回存档反复叠加。选址时可预览，同一规则负责 tooltip、在线和离线。仓储/运输本身仍按现有模型，不能把相邻等价为免费材料或省略运输。引入邻接前必须明确拆除/调整布局路径及库存、运输中的材料处理；若尚不能安全调整，不发布会永久惩罚首版布局的新规则，先只在新增区域试行。

不采用单位开雾。玩家点击地图边缘的区域卡，看到资源类型、地形用途、费用和可建位置，再一次解锁。先用确定地图/少量模板；程序随机世界与地形编辑器后置。

### 科技、时代和政策如何扩展

首批六研究沿农业/生产/仓储，长期扩展为农业生态、采集加工、建设物流、组织自动化、能源环境、防御工程六个原分支，另加民生分支；原36＋民生6候选与依赖统一放在产品目录，不再把“每时代约三研究”当上限。各内容包按实际体验冻结，未来可合并节点。研究改变配方/晋升许可/模式/运输/抗性等能力，不只累加百分比。材料研究为默认，不自动增加科研币、科学家居民或无限科技。

所谓科技树是依赖关系的可视化：图小用卡片连线；扩大后复用已装 React Flow/Dagre，仍只有一个完成集合。未来如设计“尤里卡”式折扣，需要独立定义一次性达成事实和迁移，当前不把它混入首版。

机械阶段可评估一个政策槽：农业产出、加工效率、储存能力三选一。选择是同一 GameState 的机械枚举；切换前结算此前时间，禁止按新效果追溯整段离线。首批不引入政府、外交、文化树、宗教或多个政策槽。具体效果必须在该阶段开始时依试玩冻结。

### 自动 PvE 最小规格（后续阶段提案）

- 形式选择：聚合防御与波次摘要优先于实时单位寻路。玩家点击开始章节、建设防线、选择升级，内核自动推进；动画只重放结果，不授奖。
- 第一轮只做一个边界、十波手工配置。波次数据含稳定 waveId、敌人类别/数量、强度、间隔、一次性奖励；敌人只需一种基础型和一种强敌，时代外观在后续逐步补齐。不做随机无尽难度。
- 推荐状态流：locked → preparing → running → cleared / halted。失败只暂停该防御章节，保留经济建筑和库存；不清档、不拆生产设施、不追加负资源。修复/升级后由玩家主动重试。
- 生存重大事件暂停时整个世界和战斗均冻结。无重大事件时首轮离线继续生产，防御暂停；回访先提交经济结算，再明确显示防御未推进。后续如启用离线自动防御，必须复用同一推进器按事件顺序处理消耗、伤害和奖励，不能对回访时军力简单乘离线时长。
- 建议最小状态：chapterId、waveIndex、wavePhase/remainingTicks、防御设施状态、clearedWaveIds 或等价单调奖励边界、有限 battleSummary。奖励与进度同快照提交，存储失败/重载/重播摘要不得重复发放。
- 成本消耗经济资源，奖励只加速发展或解锁外观/可选区域，基础生产进度不强制卡在 PvE。难度由已选择章节固定，玩家升时代不会自动抬高正在进行的敌人强度。
- 上述是将来进入 PvE 时的推荐起点，当前不创建战斗状态、计时器或默认启用防御；确需更复杂的伤害/护甲公式时单独缩小后再冻结。

## 产速、升级与实际收益

内核正常速度每模拟秒推进一次，渲染可每帧更新；场景约每3–5秒合并一次轻提示即可。提示频率不决定产量，不加点击收获或每5秒发钱的另一循环。首版基础速率见[首版规格](发展沙盘首版规格.md)：农田基值0.2粮/秒，1星Lv10灌溉后2.50，2星Lv10灌溉后2.90，2星Lv20灌溉后5.80，均为条件充足时的目标，并非实测入库。

当前理论输出沿原配方基值×有效等级×产能设置×`totalMultiplierFor`；该函数将稳定加成相加，灌溉0.25与2星0.20合为1.45，不是1.50。实际入库仍受材料、人力、运输、容量和运行状态限制。天气上线时再明确独立环境因子及原modifier适配，不能把原加法组误当乘法组，也不能在UI独立套公式发收益。

连续等级沿用原施工/批量目标；费用增长建议由原1.5改为自有profile的1.18，实际采用值需调参。保留成本基值×10的定义换算，成本由原函数统一输出。星级仅影响上限/能力/结构，晋升费独立于普通等级费用；不能将一个星级当新建筑重置等级或库存。

资源条同时显示库存、可用余额、净速率和容量；建筑面板区分毛产出、加工消耗、停产原因与升级后预估。净木材＝伐木产出－加工/施工等消耗，不能把每座工厂的毛产量相加标成净收益。小数库存保留至少一位、速率按需要显示两位，实际库存不因显示取整被反复截断。

升级面板以“现在→升级后”展示产速、成本和限制；材料等待估计与运输/施工时间分开。缺口资源净产速不为正时显示“需建立/恢复生产”，不能给出虚假的倒计时。研究与设施改造的估计均应在实际天气/已建状态下计算，未来天气变化时说明是当前条件估计。

## 单个营地的扩建与分层成长

| 方案             | 体验/成本取舍                                                      | 本次决定                     |
| ---------------- | ------------------------------------------------------------------ | ---------------------------- |
| 单营地连续扩展   | 建设成果始终累积在同一画面，后续需要控制地图密度和镜头             | **采用，符合用户明确选择。** |
| 多独立营地       | 擅长异地分工，但重复开局、物流和切换增加管理负担，需要适配单城内核 | 不进入当前路线。             |
| 主城＋可重玩远征 | 有短局目标，但需要独立结算、重开与奖励循环                         | 不作为当前发展主干。         |

不能因原底座只有一个Grid，就先决定产品必须做分区标签。现在采用单营地是用户的体验选择，恰好可复用现有网格/运输/离线。D1保留六初始位＋四相邻扩地位；D4再开放不同方向的小块连通土地，预览收益/费用后由玩家决定先扩林缘、河岸还是矿脉。所有扩地都与现有可达土地相连；同一镜头可看到新旧建设，放大地图后允许平移/缩放与回到营地中心，不做假多地图标签。

林缘突出木材/加工，河岸偏农业/未来环境设施，矿脉承接金属链，但不强制每块地重复配齐五建筑。资源点适建与通用空地共同形成布局选择；功能片区由建设自然长成。机械上仍是原分布式库存与运输，没有新增每区钱包；科技服务整座营地。工业污染可按有明确范围的片区计算，不代表创建第二座城市。

| 成长维度   | 频率与职责                                                    | 场景变化                                           |
| ---------- | ------------------------------------------------------------- | -------------------------------------------------- |
| 等级       | 频繁投入材料，沿原施工提升基础产能；+1/+5/到当前上限          | 每星级只设2–3个细节段，田垄/堆料/附件渐增。        |

| 科技       | 全营地一次知识/权限；前三项成基础链，工坊再开三类晋升许可     | 研究附件或新功能；不与本地晋升重复授予同一收益。   |
| 时代       | 条件达成后主动推进内容；旧建筑/土地/资源保留                  | 公共设施、道路与环境风貌改变，旧星级建筑仍可存在。 |

D1为1星上限Lv10、2星上限Lv20；后续3/4星及电气/生态的5/6星均为分批候选，不把四时代/40级写死为产品上限。晋升保留等级，不重置成Lv1，不收集重复建筑/碎片或随机抽星。时代先于相应晋升许可，经济时代不强制全研究/防御通关。营地/HQ只作预置能力与时代里程碑，无独立营地XP。

| 阶段      | 需要处理的限制                        | 科技/升级解决什么                            | 同一地块的外观                          |
| --------- | ------------------------------------- | -------------------------------------------- | --------------------------------------- |

每个时代至少新增一个改变决策的能力、一个可控约束和一处场景变化，进入新时代保持旧农田、库存和研究。首批不做遗传品种、土壤养分、疾病、死亡、逐人技能等多重隐藏负担。

## 抽象人口、天气、生态与考验

原版固定HQ设施人力适用于A/B经济包。最新C1引入人口统一供给，住房改床位，不重复消耗食物；季节/供热前置C2，健康死亡与生态分C3/C4。底座原Worker双缓冲、运输需求与取整继续核对适配，不能显示“少需25%”而真实人数未变。完整数据与事件行为统一见[生存合同](生存经营与事件体系.md)。

天气作用在原IO体系，季节/抗性/稳定研究加成的组合方式由C2唯一规则冻结。建议环境作为独立因子，而不是把原加法modifier直接当乘法；例：基础0.4、稳定加成1.25得到0.50，再乘环境0.75得0.375；这只是说明公式的纸面例子，不是已实测数值。原内核、配置与UI不得重复扣减。

林地、肥力、污染先由C4有限地块组指标表达；机械时代再追加工业排放与治理。实际生产才产生对应排放，生态压力只提高有因果联系的风险，有预警、冷却与先可达对策。首轮不建完整气象学或全球气候模型。

| 类型           | 自动推进与选择                           | 放置适配                                                             |
| -------------- | ---------------------------------------- | -------------------------------------------------------------------- |
| 常规季节与需求 | 自动变季/消耗/适用倍率；政策预先选择     | 离线同规则逐段，普通死亡在C3上线后照实记录。                         |
| 重大生存事件   | 到触发边界生成持久选项，全局暂停         | 生产/训练/消耗/人口/季节全部冻结，等待不补收益；解决后一次应用结果。 |
| 路线增益       | 阶段三选一与有限组合                     | 可稍后选择，不每季强迫暂停；营地和永久建设保留。                     |
| 自愿防御章节   | 主动开启后自动十波；第一轮离线不推进战斗 | 无重大事件时经济继续，失败只停战线；重大事件则世界/战斗一起冻结。    |

预警显示“何时、影响谁、预计变化、可做什么”；准备主要靠储备、设施、科技和有限政策，不恢复逐栋暂停/优先级微操。既有只减产/不死人提案不再限制最新生存路线，但死亡/灾害必须按阶段实现且保留应急恢复路径。所有过程沿同一模拟时间、队列与保存边界，无第二离线钱包。

960×720时场景保持主体，侧面板只显示当前对象；420×600用可收起底部面板。资源以图标＋库存＋净速率分层，环境预警占一条明确信息带；未上线天气/污染时不展示假数据。科技节点显示具体收益和前置，隐藏不可操作远期枝叶；音量/减少动效等沿原选项路径，不加每日签到与红点任务墙。

## 工程扩展路径

沿当前 Config/definitions、单一 GameState、原生产与保存链扩展。首版自有目录管理白名单/前置/地图；未来同目录追加时代内容，避免每时代一套游戏运行时。一个内容变更包含机械版本、定义、可达性、存档迁移与展示绑定；美术替换单独更新展示版本，不升级玩家机械存档。

玩法变更前先处理旧版本最后时间边界，再迁移；升级失败保留原档。D1 原型档若地图或机械结构不可能无损映射，应明确拒绝并提供原始导出/显式新档，不能悄悄清空或虚构升级成功。Windows 接入需明确从浏览器导入/导出的合同，不能把同 namespace 等同为浏览器与磁盘已经互通。

素材不阻塞全部规则，但每阶段必须有可辨认场景反馈。当前交付的 35 PNG/10 操作 SVG/四资源引用与 25 组合见[素材准备](../证据/发展沙盘/资源准备-20261018/README.md)。这些是可用于接线的原型资产；正式审批、真实等级/时代刷新、点击遮挡与缩放仍由 D1/D2 验收。

## 路线偏差检查

- 若每天工作主要在扩测试/造编辑器而没有新的可玩决定，收回到当前阶段主流程。
- 若只读预览越来越完整而真实地图仍不能建农田，下一改动必须接真实游戏。
- 若 UI 宣称开拓/工坊而内核仍按上游最大科技列变时代，属于规则偏差。
- 若为了像文明而加入逐回合、逐人派工/寻路、外交或单位微操，已偏离点击放置定位。抽象人口/食物是用户最新明确要求，沿单营地自动经营实现，不再当作偏差。
- 若一个时代只涨价格/换配色，没有新布局、生产或升级选择，先调整内容而非继续堆等级。
- 若新内容需要大量未列材料/素材才能开局，重新收敛该阶段，不顺着上游依赖全量展开。

## 最新生存扩展对原路线的修订

C0四个功能Tab不是多沙盘切换；地图仍是同一营地。C1前置首次扩地并接八类建筑/Water与Bread、住房与人口；其后保留工坊/星级成长，C2–C4再接季节、健康与生态。本文原五/七/九生产建筑统计不含新民生设施，不能继续当全产品数量。原“每区污染”沿有限地块组解释，不生成分区钱包或新城市。

当前C1已有抽象人口/食水，季节与死亡仍待后续实现。普通离线生产/消耗继续，自然死亡在对应阶段上线后同样继续；重大事件到边界全局暂停，等待不补收益，重载保持同一选项。参考来源、风险与救援防软锁合同统一见[生存经营与事件体系](生存经营与事件体系.md)，不得沿旧“离线永不死亡”或“惩罚只减效率”的提案覆盖最新选择。
