## 路径问题

当证据不能替人决定该如何生活时，谁有资格解释共同经历、制定禁忌并承受决定的后果？神学路径研究的是共同体如何把宇宙观、礼仪、记忆、责任和公共权力连在一起。它不等同于“科技不足时的解释”，也不要求所有传统走向同一宗教制度。

## 演变节点

| 节点                                | 原有难题 → 新方法与组织                                                                           | 获得的能力                                       | 代价、失效与后续问题                                                           |
| ----------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------ |
| `BEAT-PATH02-01` 见证之约           | 分散的迁徙、病痛或灾害经验难以跨代核对 → 以仪式、故事、节令和长者/仪式主持人的见证维持共同记忆    | 共同日历、互助义务和口述证词可跨家庭传播         | 记忆依赖表演者与参与者；失语、迁徙或争议会产生不同版本。谁能代表缺席者发言？   |
| `BEAT-PATH02-02` 解释职分           | 共同体扩大后，单靠熟人协商无法处理争议 → 出现训练、传承、礼仪职位和照料制度                       | 能组织大规模互助、调解、教育及长距离联系         | 职位也能垄断解释、排斥异议或将资源分配包装成神圣义务。如何复核解释者？         |
| `BEAT-PATH02-03` 多种经典与公共秩序 | 地区、城市和制度彼此接触后，旧有解释无法覆盖新群体 → 形成不同经典、改革运动、共同体协商或世俗制度 | 能以共享伦理连接陌生群体，也能提出对统治者的限制 | 统一标准可能造成分裂、边缘化和政治挪用；高阶文明仍会争论记忆、责任和共同体边界 |

失败支线：掌权者把某一版本定为唯一合法记录后，见证者转入地下、逃离或另立传承；这会保存异议，也增加误传、继承争议和相互指控。

## 证据、玩法与跨路径接口

- 证据可以是相互独立的仪式记录、口述版本、公共账目和当事人授权；必须区分可观察事件与信仰解释。
- 可形成的玩法选择包括：公开一段共同记录、保护一位拒绝公开的证人、接受某个组织的互助但受其义务约束。
- 与 `PATH-01` 科技路径交叉时，测量能检验重复条件，但不能替代共同体决定谁受益。
- 与 `PATH-03` 灵异路径交叉时，礼仪和证词可以是行动与记录，不能自动证明超自然解释。
- 与 `PATH-04` 修行路径交叉时，修习既可属于个人方法，也可受群体传承和责任约束。

## 来源边界

`SRC-33` 提醒宗教/哲学转型存在不同路径；`SRC-41` 讨论道教文本、组织和谱系演变；`SRC-43` 记录口传作为集体知识与记忆的载体。这些来源支持“制度与传统各有历史”的创作方法，不证明虚构神迹或超自然因果。
