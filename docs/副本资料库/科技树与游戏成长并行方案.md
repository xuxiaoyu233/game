# 科技树与游戏成长并行方案

日期：2026-10-07。状态：`PROG-01` 首期研究准备已实现并通过规则/存档单测；真实玩家平衡仍待试玩。文明多路径与竞争者成长仍为候选。代码事实以 `src/domain/expedition`、`src/content` 为准。

## 一、决定摘要

科技树不另开一条“点研究、看数字”的旁路。它应处在**一次远征结束之后、下一次远征开始之前**：玩家从行动中取得积分和证据，用证据发现可研究的问题，用积分解锁方法，再把一种已学会的方法编入下一局准备，从而改变下一局的行动、可选内容或风险信息。

全局成长分为四层，各自回答不同问题：

| 层             | 发生位置             | 玩家在这里做什么                                    | 跨局保留什么                                   |
| -------------- | -------------------- | --------------------------------------------------- | ---------------------------------------------- |
| 远征内策略     | 单局进行中           | 分配工人、调姿态、采集建造、决定事件/项目和迎战时机 | 只保留结算认可的事实与奖励；临时资源和建筑清空 |
| 永久基础能力   | 主空间               | 购买少量直接、易理解的永久能力                      | 已购买能力与积分余额                           |
| 研究与战术专精 | 两局之间及入本前     | 用积分学会节点；每局从已学节点中选有限专精          | 已学节点永久保留；装备选择只作用于本局         |
| 世界与故事进展 | 回归结算、调查和对白 | 带回证据、处理人物分歧、解锁世界/契约               | 已发现证据、已选分支、完成目标                 |

这四层不相互替代：研究节点不能购买故事真相；线索不能被花掉；永久基础能力不应挤掉局内策略；故事分支负责改变“之后去哪里、谁相信谁”，专精负责改变“下一局可采取什么办法”。

## 二、现有游戏基线

- 当前远征循环已经提供局内成长：工人配置、姿态、木石资源、建筑、怪潮、事件和项目。
- 当前主空间有三项一次性永久能力：`harvest-training`、`reinforced-core`、`field-repair`。规则 ID 在 `src/domain/expedition/types.ts` 中固定，价格在 `src/content/expedition.ts` 中配置，购买经 `buy-perk` 命令处理。
- 当前故事成长由线索、对白、世界与契约解锁承担。例如 `keeper-river-review` 的两个选项分别改变下一局补给，并解锁不同古城契约；这是已有的水平分支样例。
- 当前存档 `SaveBundle.schemaVersion` 为 7、机械内容为 12.0.0；共同根节点 `field-observation` 与三种单槽准备工具已进入研究面板。工具与永久能力共用积分，线索只作门槛不消耗；v11→v12 已冻结旧规则并提供显式迁移。
- Markdown 资料库不是运行时内容接口。正式机械需进入 `src/content` 和 `src/domain`，展示文案需进入 `src/themes`。

首期结构已按此原则落地，没有改动三项永久能力的含义。旧档通过显式迁移补充空研究/装备字段；不清空档案，也不重算旧局奖励。

## 三、研究带来的设计约束

1. **科技树既是机制，也是历史叙述。** Ghys 对多款历史策略游戏的比较指出，科技树既控制解锁顺序，也塑造玩家看到的文明史；节点不只可以是机器，也可以是知识、仪式和社会组织。因而本作不把文明变化写成“石器必然走向某种高级技术”的单线命运。见素材台账 `SRC-36`。
2. **先防止结构性坏树，再调数值。** Heinimäki 与 Elomaa 提出测量节点数量、依赖、可达性、成本与路径等特征；文章同时承认缺陷分类部分来自非正式论坛观察，不能当作通用质量定律。对本作可转成检查项：节点是否可达、是否存在明显压倒性路线、同层成本/能力是否相称、分支是否有实际用途。见 `SRC-37`。
3. **玩家作决定时要知道代价，作完决定后要看到回应。** Sid Meier 的 GDC 讲座报道强调有信息的取舍、短中长期目标协调，以及游戏对玩家选择的明确反馈。对应本作：购买前展示前置证据、积分成本、局内效果和后续路径；结算页告诉玩家本次新增了什么，不能只扣积分后无声结束。见 `SRC-39`。
4. **放置节奏应保留“主动行动—离线进展—回归反馈”。** 一项分析 11 款放置游戏的研究归纳了主动参与、非活跃进展、回归奖励的循环，也观察到资源管理、策略与自动化的配合。该研究以行为改变/运动游戏为应用背景，样本有限；这里借用循环结构，不据此宣称某一种研究计时或自动化方式必然最好。见 `SRC-38`。

## 四、推荐的树结构与文明史结构

### 4.1 玩家研究图：小主干、多条有代价的横向选择

研究图使用有向无环图，不要求是单一树形图。用一个很小的共同主干教会玩家“观测、记录、协作”等跨局能力；之后允许不同路径共享前置、互相交叉，或者从不同方向达到相近的能力。每条支路至少改变一项真实内容：动作、准备方案、可用契约/事件、可见风险、可控自动化或结算反馈。纯 +百分比可作为少量补充，不应成为整条路线的主体。

研究节点“学会后永久拥有”，但新研究带来的专精在入本前配置，第一版只开放一个专精位。这样玩家可以建立长期收藏，也能在森林、遗迹或未来世界之间调整做法；不会因早期点错而永久失去另一条路线。当前三项永久能力仍按旧规则累计，不强行改造成专精。

### 4.2 文明演变：能力带，不是统一科技时代按钮

从石器时代写到高等文明时，按社会需要与制度变化铺垫，而不是把时代名称当解锁条件。建议追踪六种能力：**观察/预测、记忆/证据、协作/治理、能量/物质转换、身份/连续性、维护/问责**。一个文明在哪些能力上突出、在哪些能力上脆弱，决定它的世界规则和冲突。高等文明也会有失灵、地方断层、维护负担和知识垄断。

可以把这些能力放进重复出现、但不强制按同一路径发生的历史带：

| 历史带         | 可见变化                                    | 需要写出的代价或遗留问题                           |
| -------------- | ------------------------------------------- | -------------------------------------------------- |
| 迁徙与环境适应 | 石、木、火、路线记忆、季节知识、口述传承    | 谁掌握路线；知识如何在失联或人口迁移后继续存在     |
| 聚落与分配     | 储藏、计量、劳作分工、仪式/规则、边界       | 谁管理余粮；未登记的人和异议如何处理               |
| 网络与基础设施 | 远距通信、运输、标准、档案、专业组织        | 中心与边缘的权利差、维护劳动、故障传播             |
| 能量与自动化   | 大规模能源、模型预测、机器执行、跨域系统    | 依赖链、事故责任、不可见偏差与退出权               |
| 高阶文明能力   | 跨区域/跨世界干预、身份与记忆处理、环境塑造 | 干预对象是否同意；高能力为何仍无法解决旧的伦理问题 |

这些是作者组织材料的历史带，不是游戏里必须依次点击的时代等级。一个世界可在能量转换上先进、在身份治理上原始；另一世界可依靠仪式、生态知识或修行达到类似的协作/预测能力。

当前 W-01 迷雾森林和 W-02 古城遗迹是游戏里的生存副本，不应直接等同“石器时代”和某个固定历史时代；跨时代关系要先由世界卡和主线证据建立。

### 4.3 多条知识路径共享问题，不互相换皮

`PATH-01` 科技与工程先作为第一条可落地路线。未来可以登记神学、异常/灵异、修行等路径，但每条必须有自己的知识来源、可检验方式、组织结构、能力边界与失败代价。它们不是玩家职业，也不要求一个人只能属于其中一条。

| 共通问题          | 科技与工程             | 神学与仪式                 | 异常/灵异                    | 修行与生命改造            |
| ----------------- | ---------------------- | -------------------------- | ---------------------------- | ------------------------- |
| 如何观察与预测    | 仪器、校准、统计模型   | 见证、仪轨、征兆解释       | 异常条件、边界与反例记录     | 身体感知、周期、传承功法  |
| 如何保存记忆/身份 | 档案、标准、备份       | 名号、谱系、誓约与纪念仪式 | 记忆残留、身份错位和证据污染 | 师承、心法、身体变化记录  |
| 如何协调群体      | 通信、合同、行政和协议 | 共同仪式、权威与责任       | 隔离、共识规则、风险分担     | 门派/师承、资源与实践纪律 |
| 如何转化力量      | 能源、材料、基础设施   | 祈祷、祭仪及其社会代价     | 与异常接触或限制异常         | 灵材、身体负荷、修行时间  |

表中是写作研究问题，不表示各路径能力相同，也不预判超自然现象在每个世界都真实。超自然若在某条世界线中为真，也须遵守已经建立的触发条件、限制、代价与反例。交叉节点必须有世界内的接触媒介或共同需求，不能只因为四条路线都“很强”就强行合并。

### 4.4 竞争者也有自己的成长路线

玩家研究图不等于全体角色共享的升级菜单。每位竞争者按自己的目标、资源、证据和伦理底线成长：有人争取技术方案，有人研究仪式证词，有人保存异常经历，有人追求身体实践。人物成长以世界节点和故事节拍推进，不随现实离线时间自动补跑；这样角色不会因玩家关窗就无理由超过玩家，也不会成为玩家队伍里的技能挂件。

让人物进展能被玩家观察：竞争者采用了什么方法、带回/失去了什么、下一次要争夺哪个有限机会。人物路线可能暂时合作，但合作要由目标重合和明确条件触发。资料库关系用 `CHAR`、`BEAT`、`REL` 记录；当前人物候选仍见[群像角色卡与成长弧](群像角色卡与成长弧.md)，不代表已有 NPC 成长模拟。

## 五、如何进入现有游戏循环

```mermaid
flowchart LR
  R[局内行动与选择] --> S[成功回归结算]
  S --> P[积分与永久证据]
  P --> H[主空间：研究/剧情/永久能力]
  H --> L[配置本局专精与世界契约]
  L --> N[下一局的新动作/信息/事件/压力]
  N --> R
```

规则边界：

- 普通积分仍来自项目定义的结算奖励；研究使用同一积分池，避免马上引入“科技点、神秘点、修行点”三套重复货币。购买研究与购买永久能力会有取舍，成本需要按实际回归节奏调平；不要用研究计时器再造一条离线队列。
- 线索、完成目标和世界经历只用于前置门槛，永不消耗。只有稳定的机械货币可被扣除。
- 研究、永久能力、对白选择均只在主空间通过 `GameRuntime.dispatch` 命令处理。远征中不允许中途购买并回写局内能力快照。
- 每局专精在出发前选定并写入该局快照；局内变化不修改 Profile。已学但未配置的节点可以在下一局换用。
- 结算至少反馈：本次积分来源、首次证据、因此新显现的研究节点/世界/契约，以及相关角色的可见回应。玩家已经见过的重复内容不再伪装成新发现。
- 失败、放弃与保全结算严格遵循现有结算屏障；研究点只读取最终已提交的结算奖励，拒绝命令或写入失败不能新增永久奖励。线索按现有成功/保全规则归档。离线时间不会自动研究，也不产生无法撤销的 NPC 竞速惩罚。

## 六、首个已落地纵切与后续扩展

首个纵切在已有森林—古城玩法中落地，没有依赖雪站。共同根使用已归档的 `forest-signal`；三个并列工具分别改变建设预算、实际战斗防护或调查成本。`keeper-river-review` 仍是水平叙事分支样板：故事选项改变契约/补给，科技研究改变每局准备，两者不混用同一状态。

| 稳定 ID             | 工具卡   | 前置与成本                                         | 入局效果                                   | 有意义的选择                                          |
| ------------------- | -------- | -------------------------------------------------- | ------------------------------------------ | ----------------------------------------------------- |
| `production-budget` | 营地测算 | `forest-signal`；20 积分；依赖 `field-observation` | 森林/古城首座伐木营或采石场减免 6 木、3 石 | 选择把开局资源留给生产设施，还是放弃折扣优先防守/调查 |
| `battle-bracing`    | 承力支架 | `forest-signal`；20 积分；依赖 `field-observation` | 待迎战时主动启用一次，下一波防御 +10       | 选择在哪一波兑现有限防护，预览改变实际伤害            |
| `evidence-ledger`   | 证据清单 | `forest-signal`；20 积分；依赖 `field-observation` | 森林/古城首次调查减免 4 木、8 石           | 将一部分调查成本腾给建设；每局仅首次调查使用          |

三种工具共用一个携带槽，购买研究会与 30/35/45 积分的既有永久能力竞争；线索只作门槛，不消耗。失败不撤销已购研究，局中不可换。定义还声明适用世界，雪站不携带这些效果。数值推演用于确认效果改变了实际按钮、资源或伤害，不等于玩家平衡结论。

首期三张节点卡已按以上字段映射到内容定义、主题文案和验收例。未来扩展节点时，仍记录稳定 ID、路径、前置、成本、可见效果、局内时机、机会成本、失败边界、角色关联、迁移影响和验收例。

首期已经完成“节点卡 → 森林/古城纵切 → 单槽与快照 → 规则/存档验收”。后续按需要扩展到新世界，再评估横向路径；每批核对节点成本、可达轮次、玩家是否看懂新选项、是否出现唯一最优路线，以及是否增加真实决策。节点总数不作为进度指标。

## 八、平衡与验收标准

- **图结构**：从起始条件可到达全部计划节点；无循环、孤岛和伪前置；每条路线都有可说明的用途。对同层节点比较累计成本、最短/常见解锁轮次和效果强度。
- **选择质量**：不存在适用于所有世界/所有玩家的绝对最优支路；每个选择都有明确适用场景、机会成本和可见反馈。若总是选同一路线，先检查失衡或选项是否只有文案差异。
- **循环连接**：每个研究节点都能指出哪一个真实的出发准备或局内选择被改变；如果拿掉节点，下一局没有可见变化，则先不加入。
- **节奏**：短期目标来自本局资源和事件，中期目标来自研究/契约，长期目标来自世界证据、文明路线与竞争者行动；不要一局同时弹出过多系统。
- **兼容**：购买失败不扣分；存档损坏不被自动覆盖；正在进行的 Run 使用自己的机械内容版本和出发时专精快照；关闭、重开和离线补算不重复授权研究奖励。
- **叙事**：历史带是对照工具，不是必经科技史；人物路径由自身目标和竞争行动推动，不把竞争者变成队友或玩家的科技树皮肤。

上述首期合同已通过 `check` 中的规则、迁移、余额、装备和快照测试；浏览器流程与真实对局平衡需单独验收。未来路径继续使用同一验收门槛；科技/神学/灵异/修行不是单一文明年代树的换皮。

## 参考资料

- Tuur Ghys, [“Technology Trees: Freedom and Determinism in Historical Strategy Games”](https://www.gamestudies.org/1201/articles/tuur_ghys), _Game Studies_, 2012。比较 AoE、Empire Earth、Rise of Nations、Civilization IV；从结构与历史表述分析树的必然性和分叉。
- Teemu J. Heinimäki & Tapio Elomaa, [“Quality Measures for Improving Technology Trees”](https://doi.org/10.1155/2015/975371), _International Journal of Computer Games Technology_, 2015。讨论依赖结构、成本、可达性和树质量指标；部分缺陷归纳来自非正式论坛观察，使用时保留这一限制。
- Jennifer Villareale et al., [“Enhancing Social Exergames through Idle Game Design”](https://doi.org/10.1145/3337722.3341827), FDG 2019。基于 11 款游戏归纳主动参与、离线进展、回归奖励；不是针对本作的用户研究。
- Leigh Alexander 对 Sid Meier GDC 2012 演讲的报道：[“GDC 2012: Sid Meier on how to see games as sets of interesting decisions”](https://www.gamedeveloper.com/design/gdc-2012-sid-meier-on-how-to-see-games-as-sets-of-interesting-decisions)。设计观点的二手报道，用于决策与反馈清单，不是同行评议实验。
