# 群像角色卡与独立成长弧

更新：2026-10-07。版本：候选稿 0.1。范围：为《失落航标》提供一组可修改的独立竞争者原型；不表示他们已在游戏中登场。

## 一、这组人物共同争论什么

四人被同一个难题牵在一起：**航标可以给出地点，却未必能确认地点另一端是谁；如果返航窗口有限，谁有权替另一个人决定？**他们不需要意见一致，也不是一支等玩家指挥的小队。他们分别推进自己的方案，某些目标冲突，某些关系允许短期互助。

四人的中文姓名目前是写作暂名。暂名不代表四人来自同一时代、地区或语言；也不预先决定他们如何进入中转站、能否独立接入回响片段。身份连续性必须由故事中的行动、记录或证据逐步建立，不能只凭相似外貌或名字认定。

本组的“独立升级”指每个人会改变能力、方法、资源、判断和关系状态，不套用统一战力等级。成长发生在明确的故事节点，不按现实时间挂机；角色可以失败、停滞、付出代价、退出竞争或改变目标。

## 二、候选角色卡

### `CHAR-CAND-01` 沈简：保存证据的人，也控制证据的人

- **公开目标：**保存相互矛盾的原始记录，避免某个机构或强势人物把多种解释压成唯一版本。
- **私人牵挂：**一份被整理成单一时间线的旧档，曾使一支搜寻队沿错误坐标出发。沈简后来找到几个不同版本，却无法证明被删掉的那一行是否真能救回谁。
- **方法与能力：**追查文件、印记、口述和实物的来源；重建转手与修改顺序；保留修订痕迹。
- **盲点与代价：**相信“先完整保存再说”，容易在未征得当事人同意时留存敏感材料，也可能因不愿丢弃原件而错过时机。
- **成长弧：**秘密囤积副本 → 建立可校验的来源链并区分公开/封存 → 在保留历史版本的同时承认当事人有权限制传播。
- **退场或失败方式：**被人发现保存了不应留存的记录，失去证人信任；也可能决定公开错误记录并接受无法挽回的伤害。

### `CHAR-CAND-02` 闻秋：听见求救的人，也可能替别人认定“谁在求救”

- **公开目标：**查明呼号另一端是否有具体的人，并争取一次实际回应机会；她不满足于只带回坐标和测量数据。
- **私人牵挂：**她曾听见一段极像熟人的重复呼叫，却无法区分那是有意回应、记忆回声还是系统复述。从此她既怕错过真正的求救，也怕把自己的希望强加给声音。
- **方法与能力：**观察节律与语境，和当地人建立互信，比较口述、仪式、通信残片和环境变化中的相似与差异。
- **盲点与代价：**容易把“听到声音”当成“确认一个人”，把救援变成未经同意的接回；可能为此牺牲补给、路线或他人安全。
- **成长弧：**追随声音和姓名 → 区分信号、说话者与当事人意愿 → 在仍不确定时作出可追责的选择，并接受对方也可能拒绝返回。
- **退场或失败方式：**因误判回应来源失去关键窗口；或成功找到对方，却必须接受对方不愿被救。

### `CHAR-CAND-03` 陆衡：要求复核的人，也可能把复核变成拒绝的门槛

- **公开目标：**让返航判断能被复测，降低地点错误、身份错配和同类事故再次发生的风险。
- **私人牵挂：**他曾经把坐标校准到误差很小，却没有能力证明那就是正确的返航对象。那次“测对了地点”的结果仍可能是一次失败。
- **方法与能力：**设计对照、记录误差、提出相互竞争的解释；擅长说明某条证据能支持到哪一步、还缺什么。
- **盲点与代价：**容易把不能重复的经验、证词和仪式当成噪声；面对不可逆选择时，可能用“证据不够”回避自己也在决定谁等不到。
- **成长弧：**坚持二分式通过/失败 → 公布置信范围和反证条件 → 承认行动无法等到百分之百确定，并让决策过程可审计、可追责。
- **退场或失败方式：**因等待更高确定性错过窗口；或他人揭示他的指标遗漏了重要群体，使其专业信誉受损。

### `CHAR-CAND-04` 迟遥：拒绝被定义的人，也可能让别人无从靠近

- **公开目标：**阻止航标、档案或传承把活人缩减为可定位、可复制、可取回的“对象”。
- **私人牵挂：**曾有一份记录替某个人定了身份和归属，却没有留下本人是否同意的痕迹。迟遥不愿相似的事发生在自己或别人身上。
- **方法与能力：**关注身体、记忆和关系的连续性；识别分类规则如何漏掉人；善于谈判授权、保留撤回空间。她会借用地方仪式、修行经验、技术工具或法律条文，但不把任何一种路径当成万能钥匙。
- **盲点与代价：**为避免被利用而隐藏身份线索，可能让愿意帮助的人也无法辨认她；过度拒绝记录会使伤害无法追责。
- **成长弧：**拒绝一切登记 → 为记录划定本人可理解、可撤回的边界 → 选择哪些名字和记忆愿意交给谁保管，并接受授权也带来责任。
- **退场或失败方式：**因完全隐匿而错失互助；或发现自己建立的匿名保护制度反过来掩盖了施害者。

四人都能接触多种文明路径与知识方式。沈简不等于“科技档案员”，闻秋不等于“神学家”，陆衡不等于“科学万能论者”，迟遥也不等于“修行代表”。文明路径决定人物能接触哪些工具和制度，不决定人物的全部性格。

## 三、关系网：人物之间也有自己的故事

一段关系必须有两端人物、触发事件、双方各自的理解，以及一项能看见的后果。关系可不对称，也会改变；“短暂结盟”需写清共同目标、授权边界和退出条件。

| 关系 ID                         | 两端        | 初始张力                                                         | 可能的转折                                                       |
| ------------------------------- | ----------- | ---------------------------------------------------------------- | ---------------------------------------------------------------- |
| `REL-CAND-01`（`BEAT-CAND-01`） | 闻秋 ↔ 陆衡 | 她认为等待会错失求救者；他认为先把声音当作人会造成错配。         | 闻秋愿意报告误判，陆衡才愿意为一次低置信度尝试设计止损条件。     |
| `REL-CAND-02`（`BEAT-CAND-01`） | 沈简 ↔ 陆衡 | 他要可复核的材料；沈简担心公开来源会毁掉证人或版本差异。         | 共同校验成功后仍争执原件应公开到什么程度。                       |
| `REL-CAND-03`（`BEAT-CAND-02`） | 闻秋 ↔ 迟遥 | 闻秋想靠近信号另一端；迟遥要求“被找到的人”拥有拒绝的权利。       | 只有在救援方同意先询问、并允许撤回定位授权时合作。               |
| `REL-CAND-04`（`BEAT-CAND-03`） | 沈简 → 迟遥 | 沈简替迟遥保管一份敏感记录；保护可能变成未经许可的监视。         | 一旦越权披露，旧有的保护关系转为信任破裂；之后要靠具体补救重建。 |
| `REL-CAND-05`（`BEAT-CAND-01`） | 沈简 ↔ 闻秋 | 闻秋需要信号来源来确认是否有人；沈简可能因保护来源而暂不提供。   | 她可以拒绝交换，也可以只提供经授权核验过的片段。                 |
| `REL-CAND-06`（`BEAT-CAND-04`） | 陆衡 ↔ 迟遥 | 陆衡需要身份连续性的判断条件；迟遥反对把条件写成替人定名的标准。 | 双方设计“证据可核验、身份由本人授权”的程序，但仍保留争议。       |

不是每个副本都让四人同场。主场景以两到三人为宜；缺席者可以通过一份已被改动的记录、一条独立完成的路线或一项资源变化显出他们也在行动。这样既保持群像密度，也避免每个副本都变成全员轮流发言。

#### 与现有主线副本的候选接力点

群像可以沿 W-03、W-04、W-05 的问题逐渐加深：先争“记录怎样才可信”，再争“坐标另一端是不是具体的人”，最后争“谁有权保存、发布或定义身份”。这些是候选写法，不改变三张世界卡当前状态；特别是 W-03 仍不安排活着的具名 NPC。竞争者可通过中转站的证据讨论、各自留下的行动痕迹或单独的返航请求出现，是否直接在副本中碰面需另行评审。

| 世界卡          | 群像接力点                                                                                                   | 可见的独立行动                                                                       | 不提前揭晓什么                                   |
| --------------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ | ------------------------------------------------ |
| W-03 雪线观测站 | 玩家归档 `snow-order` 后，竞争者可各自提交证据解释；不得把未实现人物节拍伪装成现行对话。                     | 通过分离保存的复核报告、请求或版本差异呈现独立行动，不默认具名角色在现场。           | 不指认最终操作者；不把进入顺序写成文明年表。     |
| W-04 多站列车   | 乘员栏缺名，坐标和返航对象拆开；闻秋想追查额外呼叫，陆衡坚持说明编号与身份的证据距离，迟遥反对替当事人填名。 | 各自提出停靠、护送或核验方案；若两人选择不同路线，之后留下的结果也可以成为竞争痕迹。 | 不把编号自动映射成姓名；不默认所有角色同行。     |
| W-05 镜像城区   | 多套地图与维护记录并存；沈简保全不同版本，陆衡尝试交叉复核，迟遥关注登记是否越过当事人授权。                 | 谁先公开、谁封存原件、谁带走一份经授权的副本，会改变下一次会面中的信任与可用证据。   | 不凭格式相同就指认伪造者；不让角色自白替代证据。 |

三张卡提供的是逐步改变的社会条件，不是石器、工业、高科技的直线等级。若其他文明支线要接入这组人物，要先决定当地如何保存记忆、分配资源、确认身份，再决定角色能采取什么行动。

这里选一条候选分支来演示“证据改变方法”，不预设所有玩家都会走同一结果：

| 阶段             | 沈简                                                                 | 闻秋                                                         | 陆衡                                                                 | 迟遥                                                           |
| ---------------- | -------------------------------------------------------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------- | -------------------------------------------------------------- |

| W-04：乘员缺名   | 发现离站/到站版本有缺页，是否交出原件取决于授权与玩家已归档证据。    | 提出偏离路线追呼，但接受必须区分“呼叫存在”与“有人愿意返回”。 | 记录编号、地点、信号来源三者的证据差距；若资源不足，可反对绕行。     | 允许使用一个可撤回的身份标记，或拒绝关联，结果由前置关系决定。 |
| W-05：路线双版本 | 首次公开可追溯的版本差异，仍封存来源人身份；因此失去一部分盟友信任。 | 根据新证据决定继续追查还是暂缓；她的目标不保证成功救援。     | 从排除不稳定材料转向给出置信范围和反证条件，仍须承担建议造成的后果。 | 可以授权有限范围核验，也可能在越权后撤回；不必和其他人和解。   |

#### 同一争论跨过文明阶段时，改变它的载体

四人不是四条文明路径的化身；他们进入不同文明的回响片段时，争论会从当地真实存在的记录、制度和生存约束中长出来。下表是写作坐标，不是历史阶段定律；具体副本必须另查地区与年代，不把复杂历史压成一条技术升级表。

| 副本文明背景（候选）  | 当地保存/验证身份的方式                        | 同一问题的新形态                                                               | 群像行动如何变化                                                                             |
| --------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| 采集与早期聚落        | 口述、刻痕、路线记忆、季节仪式、器物标记       | 一个重复的呼号/刻痕代表活人、祖先记忆，还是避险经验？谁能替群体解释？          | 沈简比对刻痕与迁徙痕迹；闻秋寻找回应者；陆衡记录周期；迟遥质疑谁有权把某人写进记号。         |
| 农牧定居与早期城市    | 粮食清册、历法、封印、家族谱系、神庙或市场登记 | 被记入名单的人是否因此就有义务、身份或返航资格？登记权掌握在谁手里？           | 争议进入粮水分配、祭仪日期和名册修订；即使文字增多，地方口述仍可能保存被删掉的版本。         |
| 机械/工业与大规模交通 | 标准时钟、车站名册、电报、印刷档案、批量调度   | 记录传播更快、互相校验更容易，但错误分类也能更快影响更多人。                   | 陆衡能比较多个时钟；闻秋追踪消息延迟；沈简核对不同印次；迟遥追问标准身份能否代表当事人同意。 |
| 信息化与高级文明      | 传感网、数据库、模型推断、生命/时空标识        | 系统可能非常准确地定位一个模式，却仍不能证明那是同一个人、其意愿或应由谁负责。 | 竞争转向授权、审计、可撤回身份和模型责任；先进工具提高证据能力，也扩大误用的范围。           |

跨阶段的变化必须来自当地人的生活方式和制度需求，不只给旧冲突换器物皮肤。若符号或制度跨时代重复，要在资料库记录它属于直接继承、传播改写、还是独立重现；相似本身不能证明共同来源。四名竞争者的成长则体现在他们逐步修正自己的方法：保全不等于无限公开，求救信号不等于本人同意，精确定位不等于正确对象，拒绝登记也不自动保护了所有人。

## 四、第一条群像线：有限返航窗口

这是写作样板，不是固定剧情结局或现有玩法。

1. **信号出现：**中转站只获得一个有限校准窗口。陆衡先公布误差范围；沈简发现旧档有不同版本；闻秋认出一段节律；迟遥注意到记录把一个人写成了坐标标签。
2. **各自行动：**闻秋主动追查声音来源；陆衡搭建对照测量；沈简核对档案链并暂缓公开来源；迟遥要求停止传播未经同意的身份信息。四人各自先做事，再发生争论，不靠一场会议解释所有设定。
3. **有限合作：**他们交换一部分材料，约定先判断“是否存在回应者”，暂不公开姓名。合作有范围，不代表互相信任。
4. **冲突兑现：**新的证据只把地点缩小到一定范围，无法消除身份不确定。返航窗口仍要选择是否尝试、由谁承担风险；每人按自己的目标行动，玩家的选择影响局势但不直接操控其他返航者。
5. **余波：**下一次出现时，变化通过具体结果可见：有人带回一份副本，有人损失校准设备，有人拒绝再共享身份线索，有人主动公布自己的误判。关系与能力发生变化，但没有人仅靠“升一级”恢复原状。

写作时不要把四个候选都变成正确的一半：可以让证据保全者误伤当事人、救援者误听信号、规则校验者拖延救援、身份拒绝者让追责更困难。人物可信度来自行为和代价，不来自作者替某一阵营背书。

### 场景试写：空着的姓名栏

以下是用于检查人物声音与关系张力的草稿，不是正式剧情或游戏文案：

> 校准板只剩一次写入机会。地点一栏逐渐收窄，姓名栏仍是空的。
>
> “地点误差已经够小，”陆衡说，“对象还不能确认。系统不该替我们补名字。”
>
> 闻秋把耳机递过去：“先听完。我没说那一定是谁。”她停了一下，又补充：“我怕再等一轮，能回答的人就不在了。这个怕不算证据，但我愿意为它承担一次尝试。”
>
> 沈简把一张有两处订正痕迹的清单推到桌边，手仍按着来源栏：“你们可以看版本差异，不能看原件。来源人还活着。”
>
> 迟遥盯着空白姓名栏：“把‘待救对象’改成‘等待本人回应’。如果最后听到的是拒绝，也要照样记下来。”
>
> 陆衡没有按下确认。他先锁住自动匹配。闻秋把手放到发送键旁，沈简收回了清单，迟遥则把撤回授权的条件写在共享记录里。没人退出，也没人交出全部材料。下一步怎么走，仍然要由各自承担选择的人回答。

场景中的冲突不是辩论赛：闻秋承认她在用希望推动行动，陆衡主动关闭自动匹配，沈简只交出部分材料，迟遥增加了新的授权条件。每个人都改变了局势，也因此让其他人付出或承担新的代价。

## 五、独立成长如何形成可追踪记录

### 写作阶段

每张卡分别维护：

```text
当前阶段 / 目标 / 方法 / 已掌握能力 / 可动用资源
已知事实与证据 / 未验证信念 / 关系变化 / 已付代价
上次行动留下的外部痕迹 / 下一步计划 / 可能失败条件
```

只有发生了选择、证据变化或关系改变，才推进成长状态。时间经过、玩家反复刷同一个副本或 LLM 生成一段夸奖，都不能单独算成长。角色成长也不总是“更强”：方法更精确、判断更谦逊、资源减少、信誉受损、目标改变，都可能是状态变化。

### 未来玩法阶段（未实现）

如果未来把独立竞争做成系统，可在每个固定故事检查点结算一次角色行动：按角色目标、现有资源与能力、关系状态、当前世界条件，在审核过的行动选项中确定结果；随后让玩家看到一条行动痕迹和一项代价。没有满足前置条件时，角色可以失败、停滞或改计划。副本关闭期间不根据现实时间自动升级。

机械状态必须由确定性规则结算；LLM 可以把已批准结果写成现场叙述，但不能决定角色获得能力、篡改证据、升级关系或写入永久档案。若把这些状态跨重启保存，需要显式存档迁移与验证，并遵守 runtime 命令边界。当前游戏尚未实现此系统。

## 六、人物卡与关系边的最小模板

新增人物时，先写能推动行动的事实，背景资料等到对应副本真正需要时再补：

```text
CHAR ID / 暂名 / 故事状态 / 当前阶段
独立目标 / 私人牵挂 / 行动方法 / 可迁移能力
不愿越过的底线 / 主要盲点 / 最近付出的代价
目前相信什么 / 哪些证据支持或反驳 / 谁知道这些事
关系 REL ID / 上次选择 / 可见行动痕迹 / 下一步计划
跨副本连续性凭据 / 可能的身份歧义 / 来源与修改记录
```

```text
REL ID / 起点 CHAR / 终点 CHAR / 受控关系词
触发 BEAT / 双方各自理解 / 当前强度与有效范围
成立条件 / 退出或破裂条件 / 可观察后果 / 状态与依据
```

角色的出生年代、语言、地区和知识传统，要在关联到具体世界卡时以历史资料和故事证据补充；不要为了快速凑齐人物小传，先把他们平均分配到四条文明路径。

## 七、定稿前检查

- 每个角色即使没有玩家在场，也有一次会改变自己处境的行动。
- 至少两段冲突发生在其他角色之间，而非四人各自向玩家提出请求。
- 竞争有具体稀缺目标和后果；合作有边界和退出条件。
- 每次返场有上次选择留下的痕迹，并推进或反驳某个已知判断。
- 每个角色既会帮到别人，也可能伤害别人；没有单一人物垄断正确答案。
- 同一角色跨副本出现时有身份连续性凭据；若只有相似影像，应记为待核验而非同一人。
- 文档内容仍标为候选；未接入 `src/content`、`src/domain`、`src/themes` 前不得称为已实现。
