## 采用规则

1. 展示名要能口述和辨认，并与副本核心冲突有关；避免只用类型词堆叠（“无限、终焉、禁区、审判”等）。
2. 先让候选名通过主线阶段、UI窄窗和朗读测试，再更新主题文案。改名只改显示字段，不改 `forest`、`ruins`、`snow-observatory` 或 `W-*` 记录 ID。
3. 不把主题名、作品名、世界名、契约名和稳定代码 ID 混作一层；旧名保留为检索别名并标日期。
4. 最终命名决议写明选用名、未选原因、适用层级和修改日期；再一并核对 README、世界卡、故事台词与游戏菜单。
