# W-03 雪线观测站：白昼刻度

更新时间：2026-10-07。状态：环境模式与首卷主线已接入代码；自动规则/存档和浏览器流程通过。真实玩家平衡与 Windows 窗口验收仍待完成。

本卡以 `src/content/expedition.ts`、`src/content/story.ts`、`src/themes/expedition-copy.ts` 与 `src/themes/story-copy.ts` 为实现事实来源。早期“双源校时簿/纸带校准”构想没有进入当前游戏，不作为玩家已发现的证据。

## 世界接续与叙事边界

森林的信号记录与古城的建站记录出现年代矛盾；`door-coordinate` 将玩家引向雪站。玩家进入前知道记录的先后互相冲突，不知道谁在选择片段、谁是返航对象，或返航要付出什么。

雪站回归得到 `snow-observatory-record`。当前主题文案表述为：三次记录是航标在不同环境保存的片段先后，森林呼号先于古城建站，雪站回波来自尚未发生的返航。带回后，`keeper-snow-debrief` 允许玩家归档 `snow-order`：进入次序不是文明从低到高的年表。该答案仍留下“操作者、返航对象与代价”三个未解问题，不揭示作者真相。

主线顺序：迷雾森林 → 古城遗迹 → 暴雪观测站 → 主空间归档片段顺序。河岸测绘是独立支线。多站列车、镜像城区及最终返航仍为后续候选。

## 当前环境模式合同

| 项目                       | 代码事实                                                                                                 |
| -------------------------- | -------------------------------------------------------------------------------------------------------- |
| 稳定世界 ID / 当前 UI 名称 | `snow-observatory` / 雪线观测站；“暴雪观测站”为旧资料别名                                                |
| 模式                       | `snow-observatory`；不声明波次日程，不进入怪潮结算条件                                                   |
| 入场状态                   | 木 8、石 8；燃料 8/12；温度 -8；发电机完整度 40/100                                                      |
| 时间与停点                 | 每节点 120 秒；共 4 节点。到节点、燃料耗尽或温度达到危险线时停止，等待玩家确认；离线补算不能跨过危险停点 |
| 温度/供暖                  | 危险线 -10，温度上限 10；供暖每秒燃料 -0.02、温度 +0.015；关闭供暖时温度每秒 -0.01                       |
| 补充燃料                   | 消耗木 6、补燃料 6，燃料最多 12                                                                          |
| 发电机修复                 | 消耗木 10、石 8，完整度 +45；一次修复后由 40 到 85，满足主线至少 75 的要求                               |
| 可用建设                   | 避难棚、伐木营、采石场；木石生产沿用统一队员/经营合同                                                    |
| 主线目标                   | 完成 3 个环境节点并将发电机修至至少 75；成功回归归档 `snow-observatory-record`                           |
| 可选目标                   | 第 4 个节点的“灯塔日志”奖励 +8 分；主线条件满足后，玩家可先安全返航，或锚定主线成果再挑战                |
| 研究准备                   | 首期生产/防御/调查工具只适用于森林与古城；雪站入场时准备槽为空；可局前组合的通用难度条款适用             |

危险停点、时间推进和修复/补燃料规则由纯领域逻辑实现；UI 通过 runtime 命令操作。存档 schema 为 7，机械内容为 12.0.0。v8 雪站只有三节点；旧活动局按对应冻结版本补算；v11 活动局先按冻结 v11 规则推进，再显式迁移且不追溯获得难度条款或随机事件。威胁升级条款会使雪站燃料消耗增加 20%。

## 固定返场变体

雪站有两个固定变体，使用相同的主线合同，以开局木石取舍改变资源空间；首局主线仍固定，不随机抽取。

| ID                      | 展示名     | 机械差异                                   |
| ----------------------- | ---------- | ------------------------------------------ |
| `snow-fuel-cache`       | 备用薪料   | 开局额外木 6；木可用于补燃料，也可投入建设 |
| `snow-radiator-salvage` | 散热器拆件 | 开局额外石 6；可用于发电机修复或建设       |

显示名/主题文案可调整，稳定 ID、奖励与前置属于机械兼容内容。变体选择保存在 Profile，入场后 RunState 持有本局变体 ID；重启、导入和离线不会重抽。

## 玩家可见的证据和表达

| 类型         | ID                         | 证据边界                                                                                       |
| ------------ | -------------------------- | ---------------------------------------------------------------------------------------------- |
| 雪站回归事实 | `snow-observatory-record`  | 三处主线环境节点完成、发电机达标并成功回归后保存；文字只说明跨环境片段顺序与回波，不指认操作者 |
| 主空间归档   | `snow-order`               | 玩家确认归档片段顺序后保存；记录岑与玩家的阶段性判断，不确认最终返航对象                       |
| 可选环境目标 | `snow-recover-lantern-log` | 第四节点是奖励目标，不改变主线证据事实；挑战前可锚定主线结果                                   |

完整短句、世界介绍和对话在主题层维护。任何后续增加的物证都应分别标出“现场可观察内容、人物推断、作者真相”，不能把旧稿的“双源校时”设想写成已经归档的事实。
