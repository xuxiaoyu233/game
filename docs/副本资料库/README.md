## 用途与权威来源

本库维护一个可不断扩展的副本素材池，包含世界种子、重复剧情骨架、变化条件、突发事件与可复用文案。目标形态是：远征不会受 W-01 至 W-08 的有限清单限制，而是从审核通过的素材中组合出具体事件；W 编号只是当前已登记的世界种子索引。组合器和 LLM 运行时生成属于后续方案，当前游戏还没有这些接口。

目标组合关系：**副本实例 = 世界种子 + 任务骨架 + 变化条件 + 本局已知状态 + 已审核事件包**。重复的是玩家能理解的节奏和决策类型；世界规则、人物关系、证据与具体突发事件负责变化。组合只能使用登记过的机械内容，不让模型临时发明数值或改变存档。交叉关系采用[交叉索引](交叉索引.md)，维护和版本规则见[交叉记录与资料治理规范](交叉记录与资料治理规范.md)。

先在本库形成故事因果与素材定义，再将通过评审的机械定义写入 `src/content`、展示文案写入 `src/themes`。游戏不会直接读取 Markdown；文档台账到游戏内容的关系以及未来机器可读投影方案见[机器可读内容桥接方案](机器可读内容桥接方案.md)。生成服务、联网方式和模型供应方都还没有实现或确定。

## 状态标记

- **现行事实**：当前文档或运行代码已确认的设定。应注明证据出处。
- **候选设定**：允许调整的故事提案；不得写成玩家已经发现的事实。
- **玩法草案**：需要新规则、状态、命令、保存和迁移评审，尚不可玩。
- **文案草稿**：可试读的文字，尚未放入主题层或 UI。

编辑性编号只用于资料库索引，不自动等于存档 ID 或正式内容 ID。建议编号：`UF-xx` 世界类型族、`PATH-xx` 文明发展路径、`PROG-xx` 成长系统、`W-xx` 世界种子、`EP-xx` 任务骨架、`EV-xx` 事件包；正式机械 ID 仍使用代码中的稳定英文 kebab-case，并需兼容性评审。

跨文档称呼统一如下：《失落航标》是当前作品主线名；“航标零号”是早期工作名，不代表第二条独立世界线。W-03 的当前 UI 名称为“雪线观测站”，“暴雪观测站”保留为旧文档别名。其余候选名称见[命名台账](命名台账.md)，不代表已经改动游戏显示文案。

## 工程化编辑闭环

资料库采用“来源台账 + 唯一 ID + 单一关系索引 + 内容卡 + 实现映射”的分工。每次新增或修订按以下顺序落笔：

1. 先在责任文档登记稳定 ID、状态和首选名称；旧名称写入[命名台账](命名台账.md)，不复用已退役 ID。
2. 为历史材料注明具体来源和实际阅读范围，将来源事实、创作推断、作者真相、角色相信与玩家证据分开。
3. 在[交叉索引](交叉索引.md)只登记需要追踪的关系边，写清方向、条件、状态和证据；人物行动和变化保留触发节点与代价。
4. 只有代码已经承接的内容才登记稳定机械 ID、文案位置和保存事实；候选内容明确写“无实现映射”。
5. 完成后运行 `npm run check:narrative-docs`（已纳入 `npm run check`），再由作者复核来源解释、历史因果、群像动机和揭示节奏。

门禁会检查项目 Markdown 本地链接、核心 ID 查重与引用、关系词登记和交叉索引中的实现路径。它不验证外部网页当前可用，也不自动判断创作内容是否正确；这些限制和 ID 唯一定义位置见[交叉记录与资料治理规范](交叉记录与资料治理规范.md)。

## 副本文案层级

同一世界可因界面位置出现不同长度，但它们必须描述同一事实，且不能提前泄露未取得的证据：

1. **入口短句**：一句话告诉玩家这里是什么地方、眼下要解决什么。
2. **世界介绍**：补足环境细节、当前冲突和行动理由；不写隐藏真相。
3. **目标说明**：只写真实机械条件；草案必须标为候选目标。
4. **证据描述**：分开记录物证上看得到的内容和人物作出的推测。
5. **回归文字**：只有成功保存的事实才进入主空间；指出它改变了什么，以及还不知道什么。
6. **返场文字**：不重复首次介绍，承认已经归档的证据，说明这次新增目标。

通用字段见[副本资料卡模板](副本资料卡模板.md)。名称、位置、人物关系和证据若会改变机械玩法，必须先写成明确规则需求，再讨论实现；不能只改描述字符串。

### 转换成《失落航标》的写作约束

- 以[失落航标设定集](../故事线设定集.md)中的玩家身份、四名投影队员、岑、回响片段和回归边界为基线；每个世界回答一个旧问题，再留一个有方向的新问题。
- 每副本有自己的局部规则、代价和可验证目标。小说中可能致命的限时和淘汰，改写为玩家可暂停的节点；关闭桌面不扣血、不叠怪，也不由台词宣布胜负。
- 线索来自可观察记录或行动结果。证据、人物推断、作者真相分别标注；角色不能凭氛围宣布结论。
- 故事奖励和经营收益必须对应已实现的结算事实。基础回归与可选证据分开，失败不抹除已归档线索，也不保留本轮未带回发现。
- 《全球死考》书单评述提醒：若推理只由主角包办，队友会失去思考空间。关键证据应让玩家能查看、比较和验证；岑的独白不能代替玩家判断，也不凭空赋予四名投影队员独立解谜能力。
- 用参考作品的**组织问题**启发原创场景，不导入原作全文、角色设定、美术、音频或标志性文本。
