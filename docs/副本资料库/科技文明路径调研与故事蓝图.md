# 科技文明路径调研与故事蓝图

日期：2026-10-07。状态：资料研究 + 原创故事候选；不是作者真相、已上线副本或科技树。交叉 ID：`PATH-01`。资料来源及阅读范围见[故事背景与素材管理](../规划/故事背景与素材管理.md)的 `SRC-16` 至 `SRC-28`；路径关系见[交叉索引](交叉索引.md)。玩家侧科技研究如何接入游戏循环见[科技树与游戏成长并行方案](科技树与游戏成长并行方案.md)；本文件侧重文明历史与世界素材，不代表系统已实现。

## 一、调研结论

科技路线不宜写成“石器—蒸汽—电气—AI”的发明清单。更有叙事价值的主轴是：**人们怎样获取能量、加工材料、保存记忆、协调远距离行动，并把决定交给制度或机器。**每次解决旧难题，都会建立新的依赖、维护工作和被排除者。

历史研究支持几条创作原则：

1. **环境压力可能推动适应，但不自动导向单一进步。** Smithsonian 汇总的奥洛盖赛利研究把水源和植被的不稳定、工具变化与群体间交换放在同一环境背景下观察；它适合启发“危机使社会改方法”，不证明每次危机必然带来技术跃迁。[Smithsonian Human Origins Program](https://humanorigins.si.edu/research/whats-hot-human-origins/unstable-environments-favored-flexibility)（`SRC-16`）
2. **技术改变社会协作，也受社会安排塑造。** Pinch 与 Bijker 的技术社会建构研究，以及 Hughes 对电力系统的历史研究，都促使我们同时写使用者、管理者、供应、标准与制度，不能只写发明者。[Pinch & Bijker](https://doi.org/10.1177/030631284014003004)（`SRC-21`）、[Hughes](https://press.jhu.edu/books/title/2031/networks-power)（`SRC-20`）
3. **能源转型会重组生产与生活，且有环境和政治外部性。** Wrigley 将煤炭带来的能源供给变化视作工业经济的重要条件；Hahn 把工业化放进跨地区贸易、殖民和劳动关系中。副本因此要问能源从哪里来、谁维护网络、成本落在谁身上。[Wrigley](https://www.cambridge.org/core/books/energy-and-the-english-industrial-revolution/A18E48989B4A915D0E77A29D57D85763)（`SRC-18`）、[Hahn](https://www.cambridge.org/core/books/technology-in-the-industrial-revolution/949B7F585E30055E0CF08828C2F50C0B)（`SRC-19`）
4. **水利交通可以成为长期治理系统。** UNESCO 对中国大运河的资料把水工建设、粮食与战略物资运输、漕运、税收和交通管制放在同一条历史网络中；工程通过多朝代扩建和维护继续运行。这个案例能让科技主线从“机器升级”转向“技术怎样支撑或约束庞大社会”。[UNESCO 大运河资料](https://whc.unesco.org/en/list/1443/)（`SRC-28`）
5. **记录技术会同时扩大记忆与行政能力。** 大英博物馆材料指出，两河流域楔形文字早期用于城市的口粮记账，之后延续三千多年并进入多类知识实践。剧情可以让账簿、档案和身份名册既救人，也成为分配权力的工具。[大英博物馆](https://www.britishmuseum.org/blog/how-write-cuneiform)（`SRC-17`）
6. **基础设施平时隐身，故障时才显形。** 电力网、铁路、通信和数据库需要标准、供应、维护和跨组织协作。挑战者号事故调查还显示，技术缺陷与信息传递、风险接受和组织决策链能够共同造成灾难；单一“坏人破坏设备”解释不够。[Star](https://doi.org/10.1177/00027649921955326)（`SRC-22`）、[NASA 挑战者号事故委员会报告](https://ntrs.nasa.gov/citations/19860015255)（`SRC-23`）
7. **高级文明的能量规模不是文明全貌（本项目的设计推论）。** Kardashev 1964 年论文讨论的是强无线电信号与外星文明的可探测性。它可以启发“可利用能量”这个指标，但公平、知识质量、政治合法性或个人福祉要另行评价；故事不把高能耗直接等同于更高文明。[Kardashev 原文](https://adsabs.harvard.edu/pdf/1964SvA.....8..217K)（`SRC-24`）
8. **数字系统能核验身份，也会把分类变成现实约束。** Bowker 与 Star 研究分类和标准如何组织社会互动；NIST 的数字身份指南和 AI 风险管理框架强调语境、安全、隐私、评测与治理。对本作的启发是：高级系统可以给出高置信度判断，仍需要追问它代表谁、允许谁申诉、如何纠错和退役。[Bowker & Star](https://mitpress.mit.edu/9780262522953/sorting-things-out/)（`SRC-25`）、[NIST 数字身份指南](https://www.nist.gov/identity-access-management/projects/nist-special-publication-800-63-digital-identity-guidelines)（`SRC-26`）、[NIST AI RMF Core](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/)（`SRC-27`）

## PATH-01 路径转折登记

这些转折是跨地区写作模板，不是一种文明必经的科技树。具体世界要再选定地区、年代和材料来源。

| 转折节点                              | 此前的限制 → 新方法/组织                                                                  | 得到的能力                                   | 新依赖、代价与失败方向                                                                                            |
| ------------------------------------- | ----------------------------------------------------------------------------------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `BEAT-PATH01-01` 共享工具与路线标记   | 单个家庭难以稳定取得材料和保存季节路线 → 通过工具互助、迁徙记忆与交换维持协作             | 共享生产和传递风险知识                       | 材料来源可能被垄断；标记的含义随迁徙而变，失败时本地知识被误读为普遍规则。参考 `SRC-16`、`SRC-40`。               |
| `BEAT-PATH01-02` 账目、度量与基础设施 | 聚落扩大后，口述承诺不足以协调水、粮、劳力和维护 → 建立账簿、历法、标准、仓储与跨地点组织 | 能分配资源、追踪责任并支持远距离工程         | 登记变成资格门槛；扩张要求持续劳动和维护。未入册者可能无法证明贡献或获得救济。参考 `SRC-17`、`SRC-20`、`SRC-28`。 |
| `BEAT-PATH01-03` 自动化与可审计系统   | 大型网络信息过多，人工难以同步 → 引入传感、数据库、算法调度与跨组织治理                   | 能快速发现模式、协调复杂系统并提供可追踪日志 | 系统继承分类偏差并放大错误；准确定位不等于身份、授权或伦理正当。参考 `SRC-22`、`SRC-23`、`SRC-25`～`SRC-27`。     |

失败/转向支线 `PATH01-BRANCH-01`：统一标准把地方做法、口传或异常记录判为噪声后，中心系统虽运行更快，却失去解释故障的关键材料；后续社会须恢复多份互相校验的账本和人工覆盖记录，代价是速度下降、重复维护增加。该分支避免“技术总是更优”，也不给任何一种知识方式永久免责。

### 文学结构转换与阅读范围

结构写法采用“旧问题 → 可观察痕迹 → 竞争解释 → 新组织/方法 → 新依赖与被排除者 → 后世如何继承或误读”，让跨时代演变通过人的行动和留存物证呈现，而非旁白宣布科技升级。`SRC-01` 仅读作品简介；`SRC-05` 仅读两段公开章节片段，观察阶段任务、回归资格、准备行为和选择后果的组织方式。它们只支持结构问题，不支持对原作全篇或工业/史前历史作结论；历史依据分别回链 `SRC-16`～`SRC-28`、`SRC-40`。

这些研究支持的是写作视角，不是本作世界观的证据。当前查阅以论文摘要、出版社介绍、官方研究机构和事故报告页面为主；部分学术专著没有逐章通读，不能据此声称完成了完整书评。

## 二、科技路径的组织方法

建议把 `PATH-01` 拆成四条互相交叉、可彼此借用的技术线。它们不是四棵互斥科技树，也不要求所有文明按同样次序发展。

| 技术线       | 早期能力               | 组织化形态                       | 高级形态                              | 长期冲突                                     |
| ------------ | ---------------------- | -------------------------------- | ------------------------------------- | -------------------------------------------- |
| 能源与材料   | 火、石料、纤维、陶土   | 炉窑、矿冶、能源网络、标准零件   | 聚变/恒星能、极端材料、跨行星基础设施 | 能源来源、供应垄断、环境代价、维护责任       |
| 记录与测量   | 口述、刻痕、季节观察   | 历法、账目、地图、度量标准、档案 | 全域传感、连续身份记录、跨时空定位    | 谁被记录、记录由谁解释、遗漏能否申诉         |
| 交通与通信   | 路线记忆、信号火、驿传 | 道路、船运、铁路、电报、电网     | 行星际中继、自治航线、时空通信        | 速度提高后，错误如何扩散；边远地区由谁服务   |
| 生命与自动化 | 工具辅助身体与照护     | 医疗、机械化劳动、自动控制       | 生命改造、自治机器、人格/记忆模拟     | 便利与依赖、工具的责任边界、复制是否等于本人 |

每一时代卡都要回答六问：旧约束是什么？新技术改变了谁的生活？知识和设备由谁维护？谁获得新权力？谁承担代价或被排除？哪些可观察痕迹会被下一时代继承或误读？

## 三、跨时代故事主干（候选）

保留《失落航标》中“返航实验、回响片段、中转站”的既有框架，但把航标放在漫长技术史的末端。主线可以追一条文明怎样从保存生活经验，一步步走向试图跨越时间接回失散者。下表是原创候选，不是已确认作者真相。

| 时代段          | 技术与生活的变化                                                               | 本段的戏剧冲突                                                                               | 带往后世的证据/问题                                                                |
| --------------- | ------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 采集与石器社会  | 识别适合加工的石料，管理火、路线和季节知识；用口述、器物和刻痕保存经验         | 一场资源变化要求迁徙；掌握路线的人要不要公开一处安全地？群体的知识如何不随讲述者离开而消失？ | 一种可复核的记号和材料来源；不能把早期社会写成缺乏复杂知识的“低级阶段”             |
| 定居与水历      | 粮食储存、陶器、水利、季节测量让协作规模增大；“什么时候分水/播种”成为公共规则  | 新水渠只能先满足部分聚落；旧的季节记忆与新历法冲突，决策者必须公布分配依据                   | 记时符号变为水渠刻度或仪式日期；后世会争论它原来是技术、仪式还是两者兼有           |
| 城市与书写      | 账目、封泥、度量衡、道路和专业工匠让远距离协作可追踪                           | 名册把粮食、劳力和居民变得可统计；未被登记的人能否领取补给、保有自己的身份？                 | 同一批材料出现公档、商账和私人记述；官方数字与生活证词不完全一致                   |
| 帝国水网与粮运  | 运河、堤坝、闸口、仓储、船运与漕运管理，把水利工程并入粮食供应、税收和交通系统 | 中央要求稳定输送，沿线聚落承担征调与维护；局部修堤可能改变下游供水和运输时限                 | 维修账、调度令、地方口述和水位标记互相印证或冲突；后世看到的是制度与工程遗产       |
| 机械与工业网络  | 矿产、燃料、机械、铁路和电报提高生产与通信尺度                                 | 停产、缺料或错误时刻表牵连多个地点；有人要求继续运行，有人坚持先停机核验                     | 旧标准进入设备和合同，产生路径依赖；旧有关系也被机器与供应链重排                   |
| 计算与自动化    | 数据库、传感器和模型整合历史记录，系统可预测路线、资源与风险                   | 系统能给出很准的坐标，却无法说明“记录中的对象是否是同一个人”；受影响的人如何质疑分类？       | 训练数据与人工修订留下审计痕迹；可靠度与授权边界成为玩家可核查材料                 |
| 高级/跨行星文明 | 能源、自动化和空间交通把远距离救援变得可行；航标系统尝试在不同时间片段中返航   | 系统将“能找到”“能重建”“应当接回”合并成一个工程目标，社会需要重新拆开这些判断                 | 返航事故令文明记录散落成回响片段；游戏主线由寻找出口扩展到判断何种返航规则值得恢复 |

### 长线递进

每个阶段都让一个概念发生变化：**记住路线 → 规定时间 → 登记人口 → 连接网络 → 计算身份 → 决定返航。**同一件遗物可以跨时代出现，但每次必须改变用途、持有者、解释或代价。铺垫不能只重复一个神秘符号；玩家应逐段看到前代决定怎样变成后代赖以生活、又难以退出的基础设施。

建议把文明路线设计成一个主要历史支干和许多开放支线：主干负责让玩家看见技术制度如何逐层形成；支线副本可以来自不同年代、文明或平行世界。科技与神学、灵异、修行的交叉点由具体社会需要决定，例如共同测量异常、照料受影响者、维护设施或决定谁能使用某项技术。每条路径都可以提供有效知识，也可能错判风险。

## 四、与当前游戏主线的衔接

1. 迷雾森林、古城和候选雪站仍是当前序章/第一卷范围，不立即改成跨时代科技史副本。
2. 暴雪观测站可以承担从“能看到时间矛盾”到“有组织的测量系统如何记录和隐瞒误差”的桥段，重点从一张神秘星图扩大到传感器、维护日志、校时标准和停机责任。具体数值、温度规则和证据 ID 仍需另行评审。
3. 中后期再让玩家进入更早的技术社会，回看相似问题如何被仪式、账册、机械和计算系统分别处理；顺序可以依证据需要前后跳跃，但每段必须有本地闭环。
4. 玩家逐步发现高级返航系统并非凭空发明：它继承了数代测量标准、资源网络、身份档案和组织选择。事故既有技术故障，也有谁有权定义目标、谁能暂停系统的问题。
5. 竞争者可以各自尝试不同技术路线、争夺有限设备/资料或提出替代方案；不能预设每人代表一条文明路线。是否具名、出身和独立行动状态另按人物卡确认。

## 五、副本与玩家选择模板

科技主题副本不能只要求“修好机器”。至少要形成以下一条完整链：

```text
社会约束 → 技术解决方案 → 受益者/依赖者/被排除者
         → 可核验的物证或系统记录 → 玩家取舍 → 返航后的可见变化
```

可供后续世界卡选用的机制方向：

- **资源网络：**燃料、电力、材料或水量只能优先供给一组设施；不同分配方案改变下一段的风险与证据条件。
- **标准与兼容：**旧设备只接受旧格式；改用新标准可以扩展网络，但会使一部分记录无法直接读取。
- **观测与维护：**自动系统在传感器故障时继续运行；玩家可缩短目标进度，也可停机交叉校准并承担额外生存成本。
- **身份与申诉：**系统提出一组匹配候选；玩家要找出误差来源、保护隐私，并决定哪些记录可写入永久档案。
- **故障传播：**一处局部维修会让其他区域失去供给；玩家需要辨认局部最优和系统后果。

这些是玩法方向，不代表当前代码已支持。实际规则进入游戏前，仍须写入玩法合同和 `src/content`；玩家可见文案进入 `src/themes`。Markdown 资料库不被游戏直接读取。

## 六、LLM 动态事件的适用边界

未来 LLM 可以围绕固定世界规则，变化表达、现场细节和局部压力，例如“某段电报延迟”“同一台设备出现两份维修记录”“居民对一次停机作出不同反应”。系统应先给出可用事件 ID、证据可见性、合法选择和资源效果；LLM 只负责本局叙述。

模型不新增技术原理、历史事实、身份匹配结论、资源、玩法选项或存档结果。发生断网、超时、拒答、矛盾或验证失败时，用固定内容继续游戏。当前项目尚无游戏内 LLM 运行时；[无限副本生成与 LLM 事件契约](无限副本生成与LLM事件契约.md)是未来设计边界，不表示该功能已实现。

## 七、主要来源与阅读范围

- `SRC-16`：Smithsonian Human Origins Program，奥洛盖赛利环境变化与早期人类行为/技术的研究摘要；引用的是研究机构对 Science Advances 论文的概述，表达“同时发生/关联”，不夸大为单因果。
- `SRC-17`：大英博物馆馆藏/策展资料，楔形文字与早期城市记账。
- `SRC-18`：E. A. Wrigley，能源与英国工业革命；本次使用 Cambridge University Press 的书籍介绍与章节摘要。
- `SRC-19`：Barbara Hahn，工业革命中的技术；本次使用 Cambridge University Press 的书籍介绍，关注全球贸易与地方/区域/全球语境。
