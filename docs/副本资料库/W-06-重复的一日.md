# W-06 重复的一日：未归档的清晨

记录 ID：`W-06`；稳定游戏 ID：无  
记录类型：候选世界种子；版本：0.1；更新时间：2026-10-07  
故事状态：候选；实现状态：未计划  
关联：`ARC-01`、`Q-04`、`PATH-01`、`PATH-02`、`PATH-03`  
真相范围：创作提案；不得作为游戏既定时间循环或现实史事实

## 进入理由

W-05 的多版本路线记录能确定街区先后，却无法解释不同来源为何重复写着同一个清晨。航标接收到一份每次都会提前一小时结束的值守清单，玩家进入旧城区核验日期、记录者和缺失的行动。

## 独有决策

保留几份互相冲突的清晨记录并承担延迟判断的风险，或先采用最常见版本恢复日常供给、让少数人的经历暂时无处登记。选择围绕“能否把共识当成事实”，不靠反复重置同一关卡制造变化。

## 候选证据与回归后果

候选证据 `day-ledger-variants`：三类独立资料记录同一日期，但对人员轮班、天气和缺席者描述不同。它可证明记录制度把不同经历并在同一天，不能单独证明时间真的循环。回归后主空间获得一套版本对照方法，后续可以比较不同回响片段的时序，而不是直接确认哪位记录者说谎。

失败分支：为尽快恢复秩序而只保留主版本，之后发现被排除者因此无法申诉；或因拒绝任何版本而错过一次可救助行动。具体规则、代价与事件 ID 待独立合同评审。

## 证据边界与回归文字

- **入口短句：**所有值守表都写着同一个清晨，缺席的人却各不相同。
- **候选回归：**日期相同不代表经历相同。我们带回了版本差异，还没有证明这一天重复发生。
- **不得写成事实：**角色拥有时间回溯能力、玩家反复进入同一日、档案自动覆盖旧存档。
