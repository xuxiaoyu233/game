## 进入理由与玩家已知

森林信号指向旧城。完成森林回归回应后，岑开放古城坐标并提供木材或石料补给；玩家进入断壁间的译码营地，回收建站记录。主线提出的核心矛盾是：古城刻出的建站日期晚于森林信号，两个地点不能直接排成一条普通历史年表。

首卷古城的作用是建立一份可复核的时间矛盾，并让玩家看到不同路线会改变契约、资源和返回证据。它不把当前古城设定成某个现实文明或固定考古年代。

## 当前玩法合同

| 项目               | 当前代码事实                                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------------------------------- |
| 稳定世界 ID / 模式 | `ruins` / `wave-survival`                                                                                           |

| 基础回归条件       | 建成避难棚并守住两波；成功回归获得 `ruins-record`                                                                   |

| 观测路线           | `ruins-observatory-contract`：避难棚、瞭望塔和防线，守住三波；可选第二座塔。成功回归可得 `ruins-observatory-record` |
| 补给路线           | `ruins-relief-contract`：避难棚、两道墙和伐木营，守住两波；成功回归可得 `ruins-relief-manifest`                     |
| 双向返场           | 首次选择的路线先开放；完成其契约目标并成功回归后，另一条路线也开放。原始对白选择与起步补给保持不变                  |
| 固定变体           | `ruins-observatory`：观测路线多 4 石；`ruins-relief-route`：补给路线多 4 木。变体与契约解锁共用规则                 |
| 隐藏调查           | 守住第一波后，可付木石解读石碑，得到临时 `ruins-script`；成功回归才归档                                             |

研究准备工具适用于森林和古城；单槽装备在入本时冻结，局中不能更换。古城与森林仍共用建设和怪潮规则；观测/补给契约改变目标组合及机会成本，没有宣称新环境模式。

## 证据与跨世界因果

| 证据 ID                    | 玩家直接看到的内容                                     | 推断边界                                         | 取得条件与归档后果                                                               |
| -------------------------- | ------------------------------------------------------ | ------------------------------------------------ | -------------------------------------------------------------------------------- |
| `ruins-record`             | 城门建站日期比森林信号日期晚许多年                     | 证明两份记录存在顺序矛盾；不单独解释形成原因     | 基础目标成功回归；与 `forest-signal` 一起开放 `keeper-revelation` 和雪站前置选择 |
| `ruins-script`             | 石碑写着航标曾重排片段；末行留下未完成的“值守员并非……” | 石碑说法需交叉核对，不等于已验证历史             | 第一波后付木石调查并成功回归；与 `forest-inscription` 一起开放隐藏核对           |
| `ruins-observatory-record` | 逆行星图指向森林河道源头，观测日期早七年               | 不证明星图是谁绘制，也不自动证明河流方向         | 选观测路线、建观测塔并守住三波，成功回归                                         |
| `ruins-relief-manifest`    | 物资名册记有营地木材储备，却没有幸存者签收             | 支持撤离队曾经过，不证明救援对象仍生存或愿意返回 | 选补给路线、建两道墙与伐木营并守住两波，成功回归                                 |

主线关系为 `forest-signal` + `ruins-record` → `keeper-revelation` → `door-coordinate` → W-03。岑把两地判断为同一次事故被切开的片段；雪站证据会进一步校正“进入先后等于文明年代”的假设。

## 失败、返场与下一问题

失守或主动撤离不归档临时石碑调查；已回归归档的记录保留。古城另一个路线的开放不改变早先的永久分支选择和补给偏好。返场可补齐不同证据，也可以沿同一契约完成可选目标。

下一问题：三段记录的次序是片段写入顺序还是文明年代？雪站给出首卷阶段答案，但操作者、返航对象和完整代价仍未知。

## 多长度文案基准

- **入口短句：**森林信号指向一座记录更晚的旧城；在断壁之间回收建站档案，并决定是否为另一条路线投入防守资源。
- **成功回归：**城门刻着建站日期，却比森林信号晚了许多年。矛盾已经归档，原因仍待核验。
- **返场：**你带回的第一份路线记录已经固定。另一条契约现在开放，可以补齐观测或撤离名册的证据。

## 交叉记录

`W-02 produces ruins-record`；`forest-signal + ruins-record requires keeper-revelation`；古城观测与补给路线形成并行证据，不决定救援对象；古城碑文为 `PATH-02` 的共同记忆/合法性与 `PATH-03` 的证词治理提供创作场景，不作为现实宗教或灵异事实。完整实现映射见[交叉索引](交叉索引.md)。
