# W-05 镜像城区：路牌的背面

更新时间：2026-10-03。版本：叙事草案 0.1。状态：候选设定 / 玩法草案；尚未实现。

## 钩子与进入理由

多站列车带回的名单版本互相矛盾，岑称自己没有改过归档。下一段坐标落在一座封存城区，路牌写着熟悉的方向，背面却有另一组仍在使用的编号。玩家去那里，不是为了证明岑有罪，而是寻找能交叉核对的记录。

## 场景与局部规则

城区由几片重复的街区叠在一起：同一个钟楼能从三条街看见，报站声却每次少一个路口。路牌的正面指导日常路线，背面保留维护编号；官方地图按街区整理，维修记录按时间登记。任何单份信息都可能过期，交叉比对两种独立来源，才能确认一条可回归路线。

规则草案：不是猜中一句隐藏口令就过关；玩家从路牌、维护登记和现场标记收集证据，更新路线判断。错误假设必须有可见矛盾或成本预告，不能由作者在结算时突然判错。

## 目标与玩法草案

- **基础目标**：通过多个路口交叉核对方向，找到满足回归条件的出口并带回城区地图。
- **附加目标**：保留一组互相冲突的路牌和维修记录，确认它们是否来自不同版本的返航名单。
- **独有决策**：用有限调查机会核实一条路线，或先保存更多矛盾证据；前者更接近出口，后者帮助判断任务来源。
- **退出边界**：已识别风险的路口才允许确认前进；调查途中可停在决策点，桌面关闭不继续推进危险。

## 候选证据与主线影响

候选证据《双面路标册》收录正面方向、背面编号和道路维护日期。三者能显示城区路线至少有两个版本，但尚不能证明是谁编写、何时合并或哪个版本正确。城区里的签收记录可以出现与岑值守编号相同的旧制式格式；格式相同只是关联线索，不是伪造证据。

主线阶段答案：路线信息确实被分层保存，玩家不应只接受任务方给的一张地图。留给卷尾的问题是：两份名单分别保护了谁，又会让谁被遗漏？这道题必须由此前带回的记录支持，不能在城区靠一段角色自白解决。

## 文案草稿

- **入口短句**：每条街都指向出口，但背面的编号把城区分成了两个版本。
- **世界介绍**：同一座钟楼能从不同街口望见，地图、路牌与维护记录却不总指向同一条路。你需要核对证据再前进，找到可以复查的回归路线；一张看似正确的地图，也可能只记录了其中一种返航方案。
- **首次回归**：城区路线至少有两个版本。编号把它们联系起来，却还不足以判断哪个版本被删改过。
