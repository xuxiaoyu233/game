# 世界卡：失籍城·第七避难环

本卡将已批准的世界设定转成实现合同；故事事实仍以[当前故事线设定集](../故事线设定集.md)为准。

| 项目     | 合同                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------- |
| 稳定 ID  | `world-unlisted-city`                                                                              |
| 卷章     | `chapter-roster-outside`                                                                           |
| 玩家目标 | 稳住第七环、带回未登记求援回执并安全回归                                                           |
| 独有规则 | `mechanic-anchor-stability` 界锚稳定度随阶段变化；影响额外区域、撤离成本和可选调查，不随机处决队员 |
| 临时资源 | `resource-energy-cell` 能芯；`resource-anchor-material` 锚材；回归时清空                           |
| 永久资源 | `界点`，只在成功结算时入账，用于改变下一局行动方案                                                 |
| 稳妥路线 | 配置生产岗位，建设避难区和锚塔，优先满足基础撤离条件                                               |
| 调查路线 | 派一名队员审计缺页街区；用短期产出或守备换取可返场补做的支线证据                                   |
| 失败边界 | 生命归零时结束当前副本；永久界点与已归档线索保留，未带回临时成果清空                               |
| 随机边界 | 每局最多一个现场异动；种子和抽选结果存档；异动不能阻断主线或随机给予永久事实                       |

## 实现验收

- 无手动采集可完成基础撤离目标。
- 稳妥经营与投入调查均有可行解，成本体现为真实人力、材料或防守缺口。
- 提前压线和行动条款在选择前展示确定奖励、资源损失与损伤风险。
- 每个事件选项在同一份内容合同中定义费用、即时结果、项目/线索结果和放弃路径。
- 只有成功回归后，未登记求援回执和支线证据才进入救援回执库。
- 保存恢复不会重抽异动；schema 7 旧档不能进入新版。
