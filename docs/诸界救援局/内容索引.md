## 内容协作约束

- 新增人物、地点、事实、证据、事件和选项前，先更新故事设定与 ID 台账，再进入 `src/content` 和 `src/themes`。
- 机械数值与稳定机械 ID 放在 `src/content`；规则只放 `src/domain`；展示文字与主题放 `src/themes`；存档只保存稳定 ID 与规则状态。
- 关系记录至少说明来源、触发条件、固定结果、证据条件和返场方式。随机事件只选择已经编写且满足前置条件的内容，不决定主线事实。
- AI 对话若将来加入，只能解释已归档事实；不可生成世界事实、规则结果、线索或永久奖励。
- 旧版内容由[历史归档](../历史资料/失落航标-v12/README.md)保管；不得复用旧版 ID 或把旧档伪装成新版存档。
