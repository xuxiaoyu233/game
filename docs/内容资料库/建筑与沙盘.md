## 一个营地持续扩张

实际空间由[camp-map](../../next/civ-idle/shared/sandbox/camp-map.ts)使用原pointy Grid定义：中心＋6个相邻位（4通用、1林地、1石脉）；首次“整修院落”一次开放4个通用位（原逻辑邻接保留）。基础链完成后支付木材10、石材5、原粮5，不能重复扣费或再次开放同一批土地。

原Grid大小45是底座逻辑尺寸，不等于玩家当前有45×45可建地。当前位置/地块编号是工程事实，玩家只见土地与对象名称；五Tab是功能分工，不是五张沙盘。

当前建设仍是供料订单；等级/目标等级/完成状态不能混同。未来搬迁、拆除、择向扩地、邻接、重复同类建筑都是后续设计，V1不能用视觉重排悄悄改变这些资格或材料归属。

## 视觉变化由什么驱动

| 输入事实 | 应变化的层 | 本批不能冒称 |
| --- | --- | --- |
| 空地→建设→完成 | 施工标识与真实建筑出现 | 背景热点等同动态建设 |
| 已完成等级段 | 田垄/器具等有限部件 | 每级必须独立整张图 |
| 本建筑1→2星 | 本建筑主结构 | 进入时代后所有建筑自动晋升 |
| 灌溉等已生效研究 | 对应功能附件 | 一个许可节点直接改变全营地产出 |
| 开拓→工坊 | 中心/公共装饰与氛围 | 1星农田已机械化 |
| 整修院落 | 同一场景中预留位置可建设 | 多城/分区切换或无限土地 |

当前原型已接线，正式素材尚不齐。V1视图预算为8个1星身份＋5个2星结构，另计中心与土地状态；三民生仍只有1星。源图、结构部件和状态选择沿[素材管线](素材与界面组件.md)，不把整幅夜间工坊画当可建地板。

## 相机与操作的边界

V1按固定场景操作范围适配原Camera，保留平移/缩放/对象定位；手机看营地与看详情切换。镜头、选中与浮层是UI状态，不改变地块坐标、规则时间、库存或存档版本。点击对象仅选择，协助/建造沿明确命令执行，拖动不发奖。

尺寸、触控、短屏、焦点和可见面积只以[网页适配规格](../设计/网页适配与视觉体验规格.md)为合同，本文不复制一套断点数值。未来设施/季节氛围仍在同一场景与同一tick上扩展。
