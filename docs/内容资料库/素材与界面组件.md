## 当前事实与制作状态

当前catalog 81项＝51个atlas-frame＋30个public-file（其中4技能徽记＋10作业图标，来源`camp-ui-icons-20261020`）；世界源PNG 51张，`town-landscape` 标记reserved、保留源文件但不进图集。A0全景/纹理另有辅助清单，不和世界条目简单相加当完成度。已有组合/程序2星结构仍属原型；高细节全景是参考和只读预览，不是整套动态建筑。

V1保持简化微缩营地方向，当前Kenney为可玩基础；统一视角、比例、落点和轮廓，低饱和土地配少量暖光。最新[源码调研](../规划/网页画质与点击体验调研-20261019.md)已查到原包SVG矢量源，先验证正确拆分导出，再对比农田/木工坊手绘微缩候选；不能把插值放大小PNG当高清。矢量与手绘不能随意混搭，风格定型以实际游戏尺寸的同场景样板为依据。不同年代换材质/设备/公共构件，保持同一画法；不切全项目像素画、不为每级每时代生成全排列。

编辑资料区分 **reference（参考）/prototype（原型）/approved（审美确认）**；是否已加载/可用与审美状态不同。这里是V1采用的管理要求，不声称catalog每个字段已完善或所有现图已获审美确认。

## 文件放哪里，谁引用

| 对象 | 当前落点/入口 | 使用规则 |
| --- | --- | --- |
| 来源、许可、处理记录 | [assets-source/SOURCES](../../next/civ-idle/assets-source/SOURCES.md)及相邻台账 | 记实际采用文件/作者/来源/版本/哈希/处理，未处理原图不机械复制两份 |
| 世界源PNG | [src/textures/sandbox](../../next/civ-idle/src/textures/sandbox/) | 作为图集输入；原图保留，修改派生件另记来源 |
| 保留不打包 | [src/textures/reserved](../../next/civ-idle/src/textures/reserved/) | 已被取代但需留档的素材（当前仅 `town-landscape.png`），不进任何图集，catalog 仍记来源与哈希 |
| 图集生成 | [prepare-atlases](../../next/civ-idle/scripts/prepare-atlases.mjs) | 先生成再类型/构建，产物位于src/images且继续忽略，不手编帧坐标 |
| 小SVG与概览图 | [public/icons](../../next/civ-idle/public/icons/)、[public/art](../../next/civ-idle/public/art/) | BASE_URL可处理路径，运行时不跨工程读旧图 |
| 唯一资源/视图绑定 | [sandbox-art-catalog](../../next/civ-idle/src/scripts/art/sandbox-art-catalog.json) | 稳定key、尺寸/锚点、来源、组合与真实状态映射，不建立第二manifest |
| 公共URL解析 | [camp-assets](../../next/civ-idle/src/scripts/art/camp-assets.ts) | key到已登记资源，不写本机绝对路径或/public URL |
| 世界部件渲染 | [camp-tile-art](../../next/civ-idle/src/scripts/art/camp-tile-art.ts) | 从真实等级/星级/研究/时代派生，不直接修改游戏事实 |
| UI图素/组件 | [ui/sandbox](../../next/civ-idle/src/scripts/ui/sandbox/)与[sandbox-tokens](../../next/civ-idle/src/css/sandbox-tokens.css) | DOM/CSS管字/按钮/面板/进度，Pixi管世界；V1按职责收敛样式 |

资源URL、sprite锚点、颜色、Tab、节点位置不写机械存档。非像素图不因“像素优化”全改nearest；小图清晰度、DPR与布局像素分别处理。

## 组件表达优先

| 需求 | 优先表达 | 详细内容 |
| --- | --- | --- |
| 资源/费用 | 图标＋名称＋数值/单位 | 来源与口径按需查看 |
| 技能成长 | 等级、进度、单次奖励、专注按钮 | 累计/名义XP与算法按需查看 |
| 建筑成长 | 对象、能力、目标选择、本次费用/效果 | 完整IO/多个目标明细按需查看 |
| 科技 | 当前六卡、必要效果/费用、状态/缺项入口 | 前置来源与长期预告不铺满首屏 |
| 异常 | 一条具体原因＋解决动作 | 恢复/数据风险保持必要说明 |
| 趋势图 | 有真实记录才画 | 没有历史数据不造曲线或用预估冒充实测 |

按钮/边框/面板优先现有React/CSS，不为文字做图片，不为六节点上图编辑器。资源图标一义一图，动作同体系，避开emoji与同义图标混杂。

## 补图与采用

先农田/木工坊同场景1星/2星对照，再补其余在用身份；缺项可交可用程序原型和精确制作单。生图需附当前真实样板，约定用途/视角/尺度/落点/透明背景/无人物文字UI；采用前看真实alpha、缩小轮廓和邻格遮挡。制作提示词不是已经生成的素材，AI图片不继承Kenney许可。

署名按实际来源逐作者保留，制作信息不挤入建设流程。开发缓存、未用整包、图集产物和玩家数据不进入发布源；后续发布沿明确指令和原站点执行。
