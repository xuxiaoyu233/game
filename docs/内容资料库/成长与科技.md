更新时间：2026-10-11。治理入口见 [README](README.md)。可以独立编写科技与文明资料，但“入库”不等于“加入首版玩法”。阶段状态只见 [PLAN](../../PLAN.md)。

## 首版成长分工

| 类型                | 解决的问题                          | 原型选择                     | 参数/文案落点                       |
| ------------------- | ----------------------------------- | ---------------------------- | ----------------------------------- |
| 技能等级            | 做这类事情积累经验、获得新活动/配方 | 采集与制作，自动升级         | content 阈值/前置；themes 名称      |
| 配方解锁            | 什么时候能将 A 变为 B               | 制作等级自动解锁             | content 输入输出/门槛               |
| 工具升级            | 消耗材料换未来效率，与目标竞争      | 一项采集工具升级             | content 成本/倍率；domain 生效语义  |
| 任务目标            | 给生产物一个可解释的消费端          | 一个维修目标，随后短故事委托 | content 成本/条件/奖励；themes 叙述 |
| 科技树              | 多条长期分支中的主动路线选择        | 暂不实现，保留候选资料       | 资料台账；进入游戏后才建机械定义    |
| 逐物品熟练度        | 长期专注某对象的额外奖励            | 暂不实现                     | 无运行时映射                        |
| 永久货币 / prestige | 跨长循环投入、重启或改变下一轮      | 暂不进入原型                 | 不沿用旧界点经济                    |

技能等级、工具和科技可以都描述“变强”，但不是同一合同。不能为了展示一张树把所有成长改成花科技点购买。

## 科技/能力卡最小模板

需要加入候选时，在本页登记索引；内容较多再分卡片。无需现在凑出 6–8 个无用途节点。

| 字段                            | 必须回答的问题                                          |
| ------------------------------- | ------------------------------------------------------- |
| 编辑 ID / 拟机械 ID、版本与状态 | 是历史、候选还是获批？是否已有运行时映射？              |
| 通用名 / 世界内名与来源         | 名称解释能力还是只装饰？资料实际读到哪里？              |
| 技能/任务/节点前置              | 前置是固定事实、等级，还是玩家主动选择？                |
| 输入成本与来源                  | 材料在哪里得到？会挤占什么已有用途？                    |
| 获得方式                        | 直接购买、研究主活动，还是任务完成？首版暂无研究活动    |
| 有限效果及参数                  | 开放哪项活动/配方、改变哪个受支持的行为？不能只写“更强” |
| 生效时点与持久性                | 当前周期、下一周期、以后所有活动还是仅本任务？          |
| 互斥/撤销语义                   | 是否必要？对存档、恢复、后悔成本有什么影响？            |
| 玩家可观察结果                  | 购买前能预览什么？之后多了什么选择？                    |
| 代码/主题/迁移映射              | 无映射时明确注明；不以资料文字直接执行效果              |

## 进入科技树的条件

只有在已有活动经济中出现长期分支，至少两种选择改变行为、不能短时无代价全购、成本有来源与真实机会成本时，才评审科技树。

若只是“做到 Lv2 后解锁修理包”，放进配方门槛；若只是“花结构件让采集更快”，放进工具。新增一种完全不同的效果，需要先扩展有限规则合同及校验/兼容处理，不能只往表里写一个任意 effect。

文明路径或技术史可以作为创作研究发展，但需要区分现实技术史、故事中角色信念和可玩机制；本轮没有新增外部文献阅读或已批准科技节点。
