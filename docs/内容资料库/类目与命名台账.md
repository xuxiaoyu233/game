## 词义与层次

| 词 | 只表示什么 | 不能混同 |
| --- | --- | --- |
| 营地 | 同一连续建设场景 | 功能Tab、多个城镇 |
| 技能等级 | 训练经验成长 | 建筑等级、时代经验 |
| 建筑等级 | 本建筑持续升级 | 星级、已完成研究数 |
| 星级/晋升 | 本建筑阶级提升 | 全营地随时代自动换星 |
| 研究 | 一次性能力/许可解锁 | 用技能XP支付、重复领取奖励 |
| 原粮/口粮 | 加工原料/居民食品 | 同一食物直接改名 |
| 人口/床位/劳动力 | 实际成人数/容量/有效能力 | 住房升级立即生产人口 |

## ID与改名边界

- 复用的上游ID保持原样，例如Aqueduct仍可显示“水井”，不为命名好看改存档。新内容沿稳定英文ID；玩家中文名不作机械键。
- S01/E01/HQ是定位编号，保留于代码/data属性/导出或开发诊断；玩家地图、详情、tooltip和无障碍名称均不显示。生产界面采用自然对象名，已有数据不因此迁移或改坐标。
- `prototype`、schema/content、原生资源ID不进入日常玩家页面；资产成熟度写制作资料，版本可在明确技术诊断查看。
- 只改显示名称不产生新资源或科技；同义词先复用已有身份。若改含义、配方/成本/资格或机械分类，转对应采用合同并审查内容兼容，不能按“文案优化”直接改变规则。
- 本库不强制创建第二份运行时字典。V1需要收拢文案时沿现展示映射/组件职责实现，避免到处复制相同名称；资料里的表格不被运行时读取。
