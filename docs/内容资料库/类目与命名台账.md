# 类目与命名台账

更新时间：2026-10-11。治理入口见 [README](README.md)。以下“当前”指 0.8.0/content14/schema9 的源码；原型词汇是规划默认候选，尚未用于运行时或存档。

## 产品概念

| 概念     | 原型建议显示                     | 责任与区别                                   |
| -------- | -------------------------------- | -------------------------------------------- |
| 技能     | 采集 / 制作                      | 经验成长轴；等级自动开放活动或配方           |
| 活动     | 收集金属 / 拆取零件 / 制作结构件 | 真正在推进的事情；全局一次一个               |
| 物品类目 | 原料 / 加工品 / 消耗品           | 资料和界面的分类，不额外制造技能或货币       |
| 工具     | 采集工具 I / II                  | 材料换长期效率；首版一项升级，不另建研究系统 |
| 任务     | 维修目标，后续故事委托           | 消费已存在物品；完成和奖励由规则判定         |
| 仓库     | 仓库                             | 查询数量与用途；首版不做仓储容量经营         |
| 故事档案 | 档案                             | 展示已获事实；不默认占据原型主导航           |

将来增加一个技能，属于机械成长定义；增加“原料”这种浏览类目，通常只是展示整理。二者不能都称为“类目”后由同一规则自动解释。

这些原型 ID 目前无运行时映射，不构成存档兼容承诺；进入 P1 定义后冻结，不复用已有不同含义的 ID。

## 世界内名称

通用操作词优先说明用途，故事层可补充世界名、人物或任务内特殊物品。展示可为“修理包（某委托使用）”，不要求玩家先从专有名词猜玩法。

当前已批准名称仍由[故事线设定集](../故事线设定集.md)维护：诸界救援局、寰门总台、失籍城·第七避难环等不在此重复定义。

当前副本资源存在 `wood → resource-energy-cell → 能芯`、`stone → resource-anchor-material → 锚材` 的槽位/内容/展示映射。驻地 `charge-cell → 蓄能芯` 是另一份库存；两个都像电芯，不代表可直接转账或合并。

## 命名变更规则

- 单纯显示名变化，编辑对应 theme 文案并更新台账；不修改 ID、存档余额或行为。
- 名称变更伴随意义、配方或库存模型改变，按机械变更处理；评估版本、冻结定义和显式迁移，不能用搜索替换伪装兼容。
- 名称别名用于资料检索，不自动授予内容、转换资源或推断剧情事实。
- 候选内容不要自动出现为锁定卡片。进入玩家界面须有真实来源、用途与解锁合同。
