# 类目与命名台账

更新时间：2026-10-11。治理入口见 [README](README.md)。当前源码指 0.8.0/content14/schema9；新技能、物品及名称都未实现。旧四物品候选已撤回为首发默认，不构成兼容承诺。

## 产品概念与首发提案

| 概念     | 玩家功能                        | 首轮设计边界                                         |
| -------- | ------------------------------- | ---------------------------------------------------- |
| 技能     | 训练并积累经验，开放活动/配方   | 推荐采掘＋金工；具体内容在 P0 冻结，可向多个技能发展 |
| 活动     | 当前正在做的事                  | 采集某原料/执行某配方；全局一个，连续重复            |
| 物品类目 | 方便查询用途                    | 原料/加工品/工具材料等展示分类，不自动成为技能或货币 |
| 工具提升 | 材料换长期效率                  | 第一档工具 II、第二档工具 III；无默认磨损            |
| 发展路线 | 看清下一步条件与用途            | 技能→活动/配方→工具/后续加工，从机械定义投影         |
| 任务     | 已有材料/事实增加目标与叙事用途 | 后续短任务，不作为技能成长唯一通道                   |
| 仓库     | 数量、来源、用途和缺口          | 不先做容量经营                                       |
| 故事档案 | 重看已获得的叙事事实            | 由批准资料与获得条件控制                             |

增加技能属于机械成长定义；增加“原料”浏览类目通常只是展示整理。技能数、行为种类、资料类目与树形页面分别决策，不能混为一种“类目”。

基础矿料、基础金属锭、工具坯、进阶矿料、进阶金属锭、复合工具坯，是 P0 共同蓝图的功能样例。具体英文 kebab-case ID 在蓝图验收前确定；题材未选定不阻止机械设计，但故事不能提前让这些词承担正史含义。

## 世界内名称与改名规则

0.8 名称由[故事线设定集](../故事线设定集.md)冻结保留，下一版从头研究；WorkBuddy 的修补、盐沼与通信方向均未获用户选定。功能名先清楚说明用途，世界内别名由批准资料映射为展示。

旧副本存在 wood→resource-energy-cell→能芯、stone→resource-anchor-material→锚材 的槽位/内容/展示映射；驻地 charge-cell→蓄能芯 是另一份库存。名字相似不代表可转账或合并。

- 单纯显示变化改 themes 与台账，不改 ID/余额/行为。
- 意义、配方或库存模型变化按机械变更处理，审查 content/schema、冻结定义与显式迁移。
- 编辑/知识/人物 ID 与机械 ID 分开；别名只用于检索和展示，不推断奖励、线索或解锁。
- 候选不能自动显示为锁定卡；只有来源、用途、门槛和实际内容都成立才进入玩家界面。
