## 本次任务如何交接

在 Issue/PR 写明输入分支与完整 HEAD、资料版本、可写范围、整合角色、验收条件和交付位置。执行者使用隔离 checkout/worktree；同一工作树一次一个写入任务，公共合同串行整合。授权范围按当前用户任务确定，不继承旧提示中的“禁止推送”或工具停用状态。

机械定义与显示文案分别进入 content/themes，规则和存档变更按当前工程合同验证。独立故事研究包只维护来源、知识、人物和因果，包外机械映射由工程审核。研究建议仍是候选，不能直接覆盖当前 PLAN。

检查分别记录静态、单测、浏览器、原生构建、Windows 交互和真人试玩。临时 HEAD、工作目录、执行者与批次放在本次 Issue/PR，长期文档只保留合同与必要证据。
