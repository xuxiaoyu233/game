## 工程边界

- 纯规则只在 src/domain；机械 ID/参数在 src/content；显示名、说明、颜色、图标素材在 src/themes。domain 不访问时钟/随机/DOM/网络/磁盘/React，app 不另写解锁计算。
- 沿用当前应用入口、Tauri 外壳和平台端口，一次一个 Runtime、动作队列和保存队列。`GameRuntime` 是完全泛型单运行时；domain 经 `RuntimeDomain` 注入，不存在第二入口或并行运行时。
- 保留启动补算、lease、保存失败重试、旧 ack 不清新 dirty、导入/关闭屏障、坏档/备份恢复合同。在线/离线复用同一推进算法，长短推进一致。
- 新档显式 namespace/profile/codec，浏览器 DB 与 lease 同时隔离；桌面固定受限 profile，不接受任意用户路径。用户主档/备份永不作为清理对象；坏档拒绝时保留原始文件。
- 开始/暂停/恢复/切换、原子扣料/产出/XP、缺料停点和工具下一完整周期生效按合同实现。
- 有限定义/ID/前置/效果，启动组装校验唯一性、引用、文案覆盖与有效参数；实际新档可达性用真实规则验证。禁止 any、关闭严格 TS 或内容脚本解释器。
- 新增同类内容若必须复制算法、按中文名判规则或增加第二状态源，停止扩内容并拆掉耦合，再继续本阶段。
- 内容/格式不兼容必须显式迁移并校验，不静默重置、不沿用旧产量补算。Tauri identifier 冻结（决定存档根目录），不随改名变动。
