## 2. 本批范围（三项，按顺序）

**A. 技能与动作图标一套（最高优先）**
- 现状：技能轨与动作行复用资源图标（木材/石材/谷物/板材），语义重复、辨识度低。
- 目标：4 个技能徽记 + 10 个作业图标，风格与既有 `town-*` 插画一致（暖色、厚描边、轻微体积感），不引入像素风或线性图标混合。
- 约束：新增素材必须登记进 `src/scripts/art/sandbox-art-catalog.json`（来源、作者/生成方式、画法、尺寸、锚点、SHA256），保留原始文件；UI 用 `CampArtIcon` 的 CSS mask 上色，不复制第二份图；不得覆盖或替换既有 `town-*` 资产。
- 验收：技能轨图标在深绿选中底与纸底上都可辨；动作行图标 15px 下仍可辨认；不改变任何规则或名称。

**B. 键盘与焦点**
- 技能轨已是 `role="tablist"`，补左右方向键切换（Home/End 可选），焦点环保持 `outline: 3px solid #235f75`；动作行动作按钮补 `aria-label`（已做“开始××”，停止同理）。
- 不引入全局快捷键冲突；不与浏览器 Tab 行为冲突。
- 验收：仅用键盘可完成“切技能 → 选动作 → 开始/停止”；焦点顺序可预期；`prefers-reduced-motion` 下不出现动画。

**C. 动效参数与节奏**
- 现有初值：飘字 0.9s、数字缓动 420ms、周期闪烁 420ms、升级脉冲 0.9s、升级提示 1.4s。
- 用真实训练（4 秒周期）观察一轮，调整到“看得见但不吵”：同一秒内不出现两次同类反馈；升级与周期闪烁不互相覆盖。
- 只改时长/曲线/颜色，不新增第二套反馈通道（不加快照、不加重叠 toast）。

## 3. 稳定核心（不得顺手改）

- 规则与数值：`shared/sandbox/**` 的作业表、XP 阈值、`planTrainingTick`、`tickCampTraining`、`skillYield`、事件/人口/经济；命令与队列 `src/scripts/sandbox/camp-commands.ts`；存档 schema5 / content `d1-c-1` 与迁移。
- 交互骨架：一次一个技能展开、单一主操作、缺口只给一个主阻塞、地图页不新增第二套经营入口。
- 视觉体系：纸/墨/林绿/麦金/赭红 token 不推翻；不引入第三套配色。
- 工程规范：非组件文件 `kebab-case.ts`、组件 `PascalCase.tsx`；严格 TS，禁止 `any`、禁止关严格模式；UI 不计算规则、不读写存档。

## 4. 验收条件（全部需要实测，不接受“应该可以”）

1. `pnpm run check:quick` 通过（格式/类型/Biome error 级）；`pnpm run build` 通过。
2. 核心合同 `node --test tests/*.mjs` 通过（本机 Node 20 缺 `stripTypeScriptTypes` 时，用 `.cache/run-contracts.mjs` 的 esbuild 垫片运行并注明；**Node 24 环境仍需复核原始方式**）。
3. 浏览器（Edge，生产构建 + preview）两尺寸 960×720 与 1440×900：无横向溢出、技能轨/动作行/资源芯片不换行错位、44px 主要目标。
4. 键盘：仅键盘完成一次完整操作；焦点环可见；`prefers-reduced-motion` 下数值直接落值。
5. 对比度：新增/改动的文字色对 ≥4.5（小字号 ≥4.5，正文 ≥4.5），在交付文档列出实测值。
6. 反馈：产物飘字、周期闪烁、升级提示三者各出现一次且不重叠；不因动画改变 `data-value` 等真实读数。
7. 旧档：用上一批存档（训练中）打开，聚焦训练技能、进度保留、无迁移。
