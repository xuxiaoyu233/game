# 图标与素材来源台账

更新日期：2026-10-16（位图同日重制，去水印）。本页登记 `src/themes/assets/` 下全部素材（内联图标字形与时代背景位图）的来源、许可与用途。素材许可发生变更时必须同步本页。

## 当前采用：内联 SVG 字形（自绘）

**来源**：本项目自绘，代码位于 `src/app/skill-prototype/Icon.tsx`（`GLYPHS` 表）。
**许可**：原创作品，无第三方许可与署名义务。
**覆盖**：12 个技能、24 件物品、7 个类目，共 43 个字形；未登记的 ID 回退到中性菱形，不会出现空洞占位。
**规格（2026-10-16 统一）**：24×24 网格、描边 1.75、圆角端点/圆角拐角、`currentColor` 描边；主行显示尺寸 1.4rem（与文本同行的活动/关系/搜索图标保持 1.2rem，避免打断行节奏）；技能/物品行外加 tone 图标容器（色相来自时代调色板，见 `src/themes/eras.ts` 的 `tones`）。

采用理由（三级降级方案的第三级，经评估后作为交付实现）：

1. 字形以 `currentColor` 描边绘制，随主题色与状态自动变色，任意尺寸清晰，不产生位图缩放噪点。
2. 体积为零（随 JS bundle 内联），不新增请求与构建步骤。
3. 视觉语言统一（同一 24×24 网格、1.75 描边、圆角端点）。混用不同作者的外部图标集会造成描边/填充风格冲突。
4. 自造物（敏捷印记、月光草、迅捷药水等）在任何公开素材库中都没有对应图标，必须自绘或生成。

**生成方式**：腾讯混元图片生成（多模态内容生成能力），提示词按时代分别描述「深色低对比抽象环境纹理」：primitive 暖褐土壤与苔绿、bronze 炉火橙与铜绿金属反光、industrial 暗铁灰与蒸汽白斜向条纹、precision 深蓝灰与仪表青冷光细网格、synthetic 近黑紫底与全息青/品红细网格光带；统一要求重暗角、极低对比、无物体/无文字/无人物。交付的 JPEG 经逐张解码校验（768×1024；平均亮度 5.1%–11.9%，最高像素 57.3%–61.1%，均为暗场低对比），并由 CSS 遮罩层（顶部线性压暗 + shell 88% 不透明底色）保证正文对比度不受影响。
**用途**：`<main>` 内 `.skill-prototype-scene` 固定图层，经 `data-era` 派生时代选择（`--era-scene` 由外壳注入），位于极光层之下、shell 之后；切换时代时同时改变场景图、极光色相、面板底色相与强调色。不新增状态、不改存档。
**许可**：AI 生成图，按生成服务条款由本项目自用；无第三方署名义务。若后续替换为人工或外部素材，须在本页重新登记来源与许可。

## 变更流程

1. 新增外部素材：下载到 `src/themes/assets/` 对应子目录，在本页登记来源链接、许可名称、署名要求与用途。
2. 许可要求署名时，同时更新 `docs/架构说明.md` 的署名位置说明与游戏内关于页。
3. 替换现有字形时保持 `Icon.tsx` 的 `iconId` 契约不变（技能/物品/类目 ID），避免触及内容与展示映射。
